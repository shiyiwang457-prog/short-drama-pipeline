# 《对白》蒸馏 (深聊台词/潜台词/语言时读)

来源:罗伯特·麦基《对白:文字、舞台、银幕的言语行为艺术》(2016,焦雄屏译)。折算靶子:1-3 分钟剧情短视频(竖屏/静音看字幕/1.5 倍速)。

三条元规则:
1. **对白的毛病通常是故事的毛病**(CH04)。台词是最后一步:文本乃一层又一层潜台词上的糖霜。
2. **声音不是选择,是结果**(CH10)。研究透角色/意义/情感/行动,声音自己长出来。
3. **场景失效时,原因往往并非字词**(CH09)。改写陷阱:新手一遍遍改错误的对白,越改越直白,潜台词全没,乏味至极。

## 一、核心概念

- **对白的完全定义**:任何角色对任何人说的任何话——对别人(传统对白)/对自己(内在对白)/对观众(旁白)。dia+legein="经过言辞的行动",所以独白也是对白。
- **三个功能**:解说(短剧降到最低,外包给画面/道具/字幕卡)、角色塑造(第一句台词内完成)、**行动**(最重要:说话本身就是做事)。任何一句只执行解说不执行行动的台词,删。
- **三个同心圆**:已说(文本)/未说(有意识的潜台词)/**不能说**(潜意识,对自己也说不出)。短剧压扁不压平:"说出来的"和"未说的"之间至少留一层落差——字面成立、动机错位("你随意"实际是最后通牒)。
- **言语行为**:每句台词=一个行动。**动名词标注法是避免"写在鼻子上"最有效的方法**:每句旁标一个进行时短语(侮辱/乞求/拖时间),标不出=废句。
- **节拍**:行动+反应。节拍改变须依策略改变;同一策略反复多少次都是一拍。**写坏的场景最早征兆=重复节拍**。短剧合理节拍密度:8-15 拍/条。
- **会话 vs 对白**:会话消耗时间维系关系;对白专注意义。可信对白不是模仿真实录音("千万别将生活印下来,要表达人生")。
- **掉尾句(悬疑句)**:核心词压到句尾才揭出。双重收益:制造悬念留人+让对手的反打镜头能紧接上。**累积句**(核心词在句首)自然但松。倍速播放下,句尾语义反转是唯一还有效的张力机制。

## 二、动笔前 12 项 (Gate,没填满就写台词=进改写陷阱)

故事层:①激励事件 ②核心价值 ③行动主轴 ④对抗力量四层清单
角色层(每人):⑤欲望对象(客观要什么) ⑥超意图(为什么非要不可) ⑦**动机 vs 借口**(真动机埋潜台词,台词说的是借口,两者不能相同) ⑧背景欲望(关系之网限定他"不能说的话") ⑨角色专属词库
场景层(每场):⑩场景意图 ⑪场景价值+起止负荷 ⑫转折点在第几拍

## 三、七步工序 (从节拍表到台词)

1. **拆节拍**:动名词对+价值负荷曲线。合格:相邻动名词不重复;曲线非直线非同向单调;在预定位置过零线
2. **五步推演**(每拍):欲望→对抗之觉察→行动选择→行动方式→表达字句。相邻拍的"行动选择"必须变化
3. **潜台词先行**:先写心里那句,再想他实际会说什么替代它。写出来=心里那句 → 重来
4. **从角色内往外写**:"如果我是这个角色处于这种情况,我会怎么办?"第一稿别停下来分析
5. **从外向内复核**:换成刷到这条的观众重看一遍
6. **台词设计**:掉尾/累积/平衡三选;简约(省掉不必要的字);静默是语言中最简约的
7. **质检**:大声念(抓意外回声)+荧光笔标核心词(专注每段说白最后一句)+跑四类瑕疵表

## 四、四类瑕疵全表 (质检核心)

### 可信性瑕疵
| 毛病 | 症状 | 改法 |
|---|---|---|
| 空洞的字眼 | 互相告知两人都已知的事("咱们认识二十年了") | 信息改造成武器/诱饵/藏起来 |
| 过度滥情 | 语言强度远超真实情感,观众在潜台词里找不到依据 | 降语言强度,或把情境垫高到配得上 |
| 过于明白 | 角色知道作者知道的(论时事的深度超出角色) | 退回角色认知边界 |
| 过度感知 | 角色比你还懂自己(弗洛伊德附体) | 删。角色不是研究资料的传声筒 |
| 借口当动机 | 童年创伤当万能动机 | 行为→动机→借口三分;动机埋潜台词,角色说的是自欺的借口 |
| 通俗剧 | **问题不是过度表达,是动机不足**。事件能量只能等于原因总和 | 不缩小动作,**加大驱动人物的力量** |

### 语言瑕疵
| 毛病 | 症状 | 改法 |
|---|---|---|
| 陈腔滥调 | 台词未出口观众已会背 | 先写下第一反应,再疯写 10-20 个选择,慎选,丢掉其余 |
| 角色中立 | 所有人说话一个味,普遍性取代特殊性 | "如果这个角色吓到必呼老天,**他**会怎么喊?"找到只属于他的字眼 |
| 雕琢 | 自觉的文学腔,向作者喊"我写得多聪明" | 有怀疑,就把声调压一压 |
| 干巴巴 | 多音节长句虚弱无力 | 八条:写实在不抽象/写熟悉不陌生/**短字**/**直接不迂回**(银幕对白一闪而过,竖屏+倍速+静音下成倍加强)/主动不被动/**短句**/表达不模仿/**删多余词**(嗨哦那也是——小碎嘴不使角色真实,像穿运动裤不代表是运动员) |

选词四倾向:人越激动词句越短;越主动直接词句越短;越聪明句子越复杂;越渊博词汇越多。

### 内容瑕疵
| 毛病 | 症状 | 改法 |
|---|---|---|
| **写在鼻子上**(最普遍最毁灭) | 把全部思维和最深情感直接写出来念。判据:**演员没法演**(演的不是话是动作) | ①动名词标注 ②追问潜台词动机("为什么这对情人要制造电影般的场景?他们关系出了什么问题?") ③豁免:非写实类型(寓言/夸张喜剧/爽剧)合法使用 |
| 内心独白谬误 | 长篇大论不被打断,角色沦为作者传声筒(两分钟≈300 词,无反应就过量) | 插入对方的非语言反应,打断成行动/反应节拍 |
| 两人对话病 | 面对面直给,砖头般僵硬,没有被保留的不可说 | **三边对话**:第三者当争斗出口——在场第三人/一件物品(酒、体检报告)/缺席者(不在场的婆婆/前任)/文化符号。物品和缺席者在短剧成本最低效果最好 |

### 设计瑕疵
| 毛病 | 症状 | 改法 |
|---|---|---|
| 意外的回声 | 同字同音重复没被发现 | 每稿录音大声念,回声跳出来立删 |
| **重复的节拍**(更大危险) | 同价值负荷连排(正正正/负负负),用不同的词重复同一拍,自欺"重复是强化" | 回报递减:第一次全效/第二次半效/第三次踢自己。把"拒绝"变行动、"乞求"变反应,扭转重组 |
| 模糊的意义 | 泛指名词+模糊动词+画蛇添足的修饰("用力善用一个大钉子") | 换具体意象("锤一个长钉") |
| 错失意义时机 | 太晚=絮叨到观众先猜中;太快=意义开头后面拖拉 | 最少的词表述最多;三种句设计自由控制意义落点 |
| 错失提示时机 | 核心词太早出现,对手只能干等 A 把话说完(现场只会:互相打断/重叠/假礼貌) | **每句最后的字词=核心词**;荧光笔逐句标,句尾还飘着的删改重组 |
| 转折点错位 | 太早(开场即泄,一路反高潮)/太晚(观众早猜到)/不出现(负荷从头到尾没变,"这些谈话是干嘛的?") | 一拍一拍建向转折点,把握缓急 |
| 分岔的场景 | 潜台词与正文本不合拍。四因:①动机在对白平(乏味) ②动机弱对白炸(滥情) ③内外不相关(莫名其妙) ④与环境无冲突(风平浪静) | 从内到外改造(建深层欲望再外放),比从外到内(重写对白配动机)更难但收益更大。警告:俚俗化(塞脏字)救不了无趣——不说话的黑道分子才最狠 |
| 改写陷阱 | 一遍遍改字,潜台词改没了 | 回 12 项 Gate,问题在事件和角色设计里 |

## 五、角色专属词库 (六维填写)

| 维度 | 填什么 | 判据示例 |
|---|---|---|
| ①词汇(关键) | 只有他会用的名词/动词各 5-10 个 | 同样谈酒:迈尔斯"皮薄/呵护/令人心痛";玛雅"生命/太阳/巅峰"——词库不同人格即不同 |
| ②语法 | 名词动词=知识范围("大钉子"=无知,"塞钉/片钉"=行家);修饰语=个性(好大 vs 壮丽;超猛 vs 很快;主动/被动式;情态动词:能/必须/应该) | 情态动词传达他对可能/许可/必要的态度 |
| ③节奏 | 句长+是否成句 | 托尼:单音字,≤10 词,不成句("票…走,走");梅菲:25 词完整句 |
| ④音调 | 开口习惯/语气词/停顿 | 夏洛特:被动动词+泛指名词+零形容词="单调无生气的人生" |
| ⑤文化 | 他会引用什么符号 | 每场戏挖一个文化符号做三边对话的第三样事物 |
| ⑥维度 | 支撑本性的矛盾 | 从对白里能读出的矛盾对(杰克七维) |

**验收=调换测试**:A 的任意一句放进 B 嘴里不违和 → 失败重做。
冲突升级时的通则:冲突渐高,人越激动越主动,说话越简短甚至不说;到高潮时人会说出以后后悔的蠢话。

## 六、六种冲突类型 × 短剧适用

| 类型 | 定义 | 短剧适用 |
|---|---|---|
| 均衡冲突 | 势均力敌的两人对峙 | ★★★ 职场/情感默认款 |
| 喜剧冲突 | 均衡冲突夸张到疯狂极限;喜剧角色核心设计=盲目 | ★★★ 四技巧:清晰/夸张/时机(一击之后不可再有台词,留 0.5-1 秒给观众笑)/不协调 |
| 不对称冲突 | 一方口头挑衅+一方沉默抵抗 | ★★★ 竖屏最优:沉默方的反应特写=免费第二机位,不耗台词时长 |
| 非直接冲突 | 语言藏反感、操控,不正面交锋 | ★★ 需配更明确的表演提示 |
| 自反性冲突 | 说话的自我 vs 沉默的自我 | ★ 几乎不可用(需旁白独白) |
| 微限冲突 | 最少对白+最大力量,与空虚冲突 | ★★ 高级高风险;但其"两条价值线交替升降"的节拍法值得全盘借鉴 |

## 七、媒介特有坑 (麦基没覆盖)

1. **前 3 秒钩子台词**:第一句同时完成亮冲突+亮关系+抛未答问题;把最刺的词放第一句句尾
2. **静音观看**:潜台词从"语气"迁移到"用词选择"(不靠语气阴阳,靠"您可真是我亲姐"的词汇错位)
3. **字幕行长**:一句 ≤ 一行字幕(12-16 字),超行=设计失败;这条自动执行短字/短句/删多余词
4. **1.5 倍速**:停顿失效,张力只能靠句尾语义反转
5. **素人演员**:台词必须写到"念出来就对";大声念检查从可选升级为强制
6. **金句需求**:每条片指定 1 句,同时满足:角色专属词汇+掉尾句+≤12 字+脱离剧情独立成立
7. **第一句=人设**:第一句台词强制命中该角色至少 1 个专属名词/动词+1 个情态习惯
8. **反馈回路**:发布后用完播率曲线反查掉率点在第几拍,倒推是重复节拍还是转折点太晚
