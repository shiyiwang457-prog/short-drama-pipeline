# 诊断手册 (每次开诊必读)

## 一、节拍表模板 (第 2 步触诊用)

每行一个节拍。节拍 = 一次"动作/反应"交换;**只要双方行为性质没变,来回十句仍是同一拍**;行为可辨认地变了(哀求→威胁)才进新拍。

```
序号 | 秒数 | 动作(进行时短语,带情感色彩) | 反应(进行时短语) | 价值负荷 | 潜台词一行
```

- 动作/反应措辞的精度 = 分析的精度:"正在恳求"(有庄重感) vs "趴在她脚下"(卑躬屈膝),选词本身是判断
- "拒绝反应"(直瞪瞪看着不接话)也是反应;非人物力量(一份报告、一通电话、药效)也能占节拍位
- 价值负荷标 + / − / ++ / −−,允许带倾角("总体负但有一线希望"记 −+)
- 表旁画价值曲线,标出翻转次数和最终转折点位置

**节拍配额(短视频硬参数)**:

| 时长 | 场景数 | 节拍数 | 每拍时长 | 价值翻转次数 |
|---|---|---|---|---|
| 60 秒 | 1-2 | 8-12 | 5-8 秒 | ≥2 |
| 90 秒 | 2-3 | 12-16 | 5-8 秒 | 3 |
| 180 秒 | 3-5 | 18-26 | 6-10 秒 | 3-4 |

低于配额=拖,高于=观众接不住。

## 二、短视频硬参数 (诊断阈值)

| 参数 | 阈值 | 出处 |
|---|---|---|
| 激励事件 | 前 5-8 秒内(0-3 秒伏笔画面失衡 + 3-8 秒分晓) | 《故事》CH08 折算 |
| 类型信号 | 前 3 秒打满(类型标签替代第一幕建置) | 《故事》CH04 折算 |
| 善之中心 | 前 5 秒建立(把周围写得更坏,不是把主角写得更好) | 《故事》CH16 |
| 巧合红线 | 中点(45 秒 @90s)之后禁用;**用巧合转折结局 = 致命,无例外**(喜剧豁免:主角已吃足苦头+从不气馁) | 《故事》CH16 |
| 巧合唯一合法位 | 0-8 秒当激励事件,让它有 80 秒积累意义 | 《故事》CH08 |
| 弧光 | 单集只做揭示(观众认知变,人物不变);变化留给跨集 | 《人物》CH11 |
| 字幕行长 | 一句台词 ≤ 一行字幕(12-16 字),超了=设计失败 | 媒介约束 |
| 停顿 | ≤1 秒,且必须同时给表情特写或字幕停留(静音+倍速场景) | 媒介约束 |
| 静音适配 | 潜台词必须落在**用词选择**上,不能只靠语气(静音看字幕时语调层全部消失) | 媒介约束×《对白》CH10 |
| 金句 | 每条片 1 句:角色专属词汇+核心词在句尾+≤12字+脱离剧情独立成立 | 传播需求 |
| 结尾 | 最后 1-2 秒定格/反应镜头(基调形象),不直接切黑 | 《故事》CH13 折算 |

## 三、诊断表① 剧情不打动人 (故事层)

| # | 症状 | 病根 | 书证 | 处方 |
|---|---|---|---|---|
| S1 | 看完没感觉/"平" | 价值没翻转:开篇负荷=结尾负荷 → 非事件。情绪是价值翻转的副产品,不是惨戏的副产品 | 《故事》CH02/CH11 | 找出这场押的价值,让曲线过零线;过不了就删场 |
| S2 | 不关心主角死活 | 移情没建立:无善之中心 / 主角是上风狗 | 《故事》CH16、《人物》CH16 | 前 5 秒先亮出比他更坏的人/制度;把胜算压到渺茫 |
| S3 | 反转"编得真假" | 巧合转折(60-80 秒恰好路过/恰好听见/恰好是他表哥)= 机器降神 | 《故事》CH16 | 改成人物选择或早埋伏笔驱动;巧合非要不可就前移到 0-8 秒 |
| S4 | 反转"看不懂为什么" | 反转三判据缺项:出乎意料 / 在人物内的情理之中 / 回望有迹可循,三缺一 | 《人物》CH16 | 补伏笔(逻辑是后创作的:先有精彩转折,回头把它变合理) |
| S5 | 该哭的地方想笑 | 回报递减:连续同号情绪。第一场哭、第二场吸鼻子、第三场笑场 | 《故事》CH10 | 正负交替;惨前垫一拍暖 |
| S6 | 结尾没劲/泄气 | 倒数第二拍与最后一拍价值同号(爽铺爽、惨铺惨) | 《故事》CH09/CH13 | 最后翻转前那一拍钉死在相反价值上 |
| S7 | 中段划走 | 重复节拍:人物在做前面已试过的同级动作(不归点失效) | 《故事》CH09 | 每次鸿沟裂开后,同等力度性质的行动全部排除出故事 |
| S8 | 开头 3 秒抓不住 | 激励事件太晚 / 类型信号没打满 / 从"平静"开始铺 | 硬参数表 | 开场即失衡:第一句台词就是转折点之后的状态 |
| S9 | 冲突像假的 | 双方欲望只是相切,不是直接相对 | 《故事》CH11 第一步 | 重写两个目的状语("为了X"vs"为了非X"),必须正面相撞 |
| S10 | 选择没分量 | 危机是善恶/是非选择(观众能提前算出结果=不是选择) | 《故事》CH10/CH13 | 改成真两难:两善取一或两恶取轻;升三方结构(得B必失C) |
| S11 | 高潮要靠台词解释 | 高潮动作不自明 | 《故事》CH13 | 换成不需要任何解释的动作 |
| S12 | 全片烂大街 | 作者不了解这个世界(陈词滥调的唯一根源) | 《故事》CH03 | 回定题层:世界界定表+把世界缩小到全知尺寸 |
| S13 | 解说噎人 | 互相告知已知事(空洞字眼)/信息硬灌 | 《对白》CH06、《故事》CH15 | 解说变弹药:让人物拿已知的事当武器争夺;能推断的全删;秘密留最后 |
| S14 | 悬念策略不对 | 全片用"神秘"(观众知道得比人物少)当主策略 → 只换来好奇,换不来移情 | 《故事》CH16 | 默认:前 3-5 秒戏剧反讽起手(观众上帝位)→中段悬念→最后一拍披露 |

## 四、诊断表② 人物不鲜活 (人物层)

| # | 症状 | 病根 | 书证 | 处方 |
|---|---|---|---|---|
| C1 | 像纸片人 | 只有特征清单没有维度。维度=矛盾:"勇敢"不是维度,"勇敢/怯懦"才是;特征清单再长也不产生一克维度 | 《人物》CH09 | 给一对矛盾,满足三判据:一以贯之(≥2 次发作)+多变(不同情境不同发作)+显得无解 |
| C2 | 一眼看透/没嚼头 | 塑造=真相("水泥板":内在外表一模一样) | 《人物》CH05 | 拉开表里落差:看似 A 实则 B;观众看完外表必须会问"他到底是谁" |
| C3 | 是工具人 | 从不做选择,被剧情推着走。压力下的选择是揭示人物的唯一通路 | 《人物》CH08 | 给他一个两难;风险压力越大揭示越深;选择越自由揭示越深 |
| C4 | 台词谁说都行 | 角色专属词库失败。调换测试:A 的台词放 B 嘴里不违和=重做 | 《对白》CH10 | 每人 5 个专属名词+5 个专属动词;第一句台词至少命中 1 个 |
| C5 | 有设定但演不出来 | **对手太弱:复杂性 ≤ 对抗力量**。维度是被对抗力量逼出来的,没有压力维度是死的 | 《人物》CH10 | ★反直觉:改对手不改人物。对抗力量分三层加(内心/个人/个人外) |
| C6 | 欲望空洞 | "想过得更好"是抽象名词不是欲望目标 | 《人物》CH08 | 换成具体的物/情境/经历,一句话说得出 |
| C7 | 主角讨喜但没人心疼 | 混淆同情与移情:可爱≠"像我"。移情才是必需 | 《故事》CH07 | 找移情钩子:观众在他身上认出的共通人性(下风狗处境是最便宜的钩子) |
| C8 | 动机像贴上去的 | 借口当动机(童年创伤万能包) | 《对白》CH06 | 区分行为→动机→借口;真动机埋潜台词,台词里说的是他的借口 |
| C9 | 人设崩了 | 违反"一以贯之":救猫的人突然踢狗(编剧手滑,不是维度) | 《人物》CH09 | 要么删,要么把两面都做成反复出现的型制 |
| C10 | 系列账号人物越拍越淡 | 单集想做弧光(短期突变是临时的、表面的、易逆转的) | 《人物》CH11 | 单集只揭示;维度跨集累积(第1集护猫→第7集冷看人挨打→第15集观众拼出维度);弧光留给季 |

**单集验收两问**(每条片必过):这一集开始时观众以为她是谁?结束时观众知道她是谁?两个答案必须不同——变的是观众认知,不是人物。

## 五、诊断表③ 关系不咬合 (关系层)

| # | 症状 | 病根 | 书证 | 处方 |
|---|---|---|---|---|
| R1 | 配角可有可无 | 说不出他照亮主角哪一维 | 《人物》CH17 | 傲慢与偏见算式:零维配角一个特性,精确顶住主角一维;顶不住就删 |
| R2 | 俩人像一个人 | 同桌测试失败:出事时(洒了酒/宣布离婚)两人反应相同 | 《故事》角色两极分化 | 合并成一个,或重设其中一个的反应轴 |
| R3 | 关系是死的 | 权力从头到尾不消长 | 《人物》CH17 | 每场标"谁上谁下",让它至少翻一次 |
| R4 | 对手戏僵硬像念稿 | 两人对话病:面对面直给,没有被保留的不可说 | 《对白》CH08 | 三边对话:塞一个第三者当出口——一件物品(体检报告/手机)或一个缺席者(不在场的婆婆/前任/老板),成本最低效果最好 |
| R5 | 配角抢戏翻船 | 配角比主角有维度 → 善之中心偏移、焦点失衡 | 《人物》CH17 | 维度配额:主角 3+,第一圈 1-2,第二圈 0(只给一个鲜明特性),第三圈 0 无名 |
| R6 | 群像散 | 职位重复:两个角色占同一职位/用同样方式做同样的事 | 《人物》CH06 | 一个职位一个人;方式必须彼此不同 |
| R7 | 反派扁 | 把对抗力量写成一个坏蛋。对抗力量=反对意志与欲望的所有力量总和 | 《故事》CH14 | 不加人物,把对抗分散到三层:内心的(她也想信对方)+个人的(她妈站对面)+个人外的(规则/时间/钱) |

## 六、根因路由表 (每个处方必附)

| 症状形态 | 表面像 | 根在 |
|---|---|---|
| 台词不像人话/有回声/核心词不在句尾 | 对白 | 对白层,就地改 |
| 台词改了几遍还不对劲 | 对白 | **故事层**(事件与场景设计),改写陷阱警告 |
| 场景平、没发生事 | 故事 | 故事层(价值没翻) |
| 人物扁 | 人物 | 人物层(维度缺失) |
| 人物有维度但演不出来 | 人物 | **故事层**(对抗力量不够) |
| 观众不心疼主角 | 人物 | 人物层(善之中心/移情钩子) |
| 全片烂大街 | 说不清 | **定题层**(不了解世界) |
| 数据崩了 | 说不清 | 先查类型四件套:核心事件缺席?核心价值没翻转? |

## 七、类型四件套速查 (问诊第 1 步用)

**命运情节十型**(人物不变化,靠选择自我揭示;系列账号主线默认走这档):

| 类型 | 核心价值 | 核心事件 | 核心情感 | 核心卡司 |
|---|---|---|---|---|
| 动作 | 生/死 | 英雄命垂恶棍之手 | 兴奋 | 英雄、恶棍、受害者 |
| 恐怖 | 生存/诅咒 | 同上 | 恐惧 | 怪兽、受害者 |
| 犯罪 | 正义/非正义 | 同上 | 悬疑 | 反英雄、恶棍、受害者 |
| 爱情 | 圆满/失败 | 恋爱行为 | 渴望爱情 | 恋人 |
| 家庭 | 团圆/分离 | 家庭团圆或分裂 | 渴望团圆 | 一个家庭 |
| 战争 | 胜利/失败 | 决战 | 悲痛的恐惧 | 士兵、敌人 |
| 社会 | 问题/解决 | 鉴别危机 | 道德义愤 | 社会领袖、受害者 |
| 政治 | 强权/弱势 | 强权或胜或败 | 渴慕胜利 | 交战双方 |
| 现代史诗 | 暴政/自由 | 反叛行为 | 道德勇气 | 暴君、叛贼 |
| 事业 | 成功/失败 | 职业失败 | 鼓劲加油 | 主人公、机构 |

**性格情节六型**(唯一带弧光的六个;留给跨集长线,单集别碰):救赎(道德救赎行为)/堕落(**不可逆转的非道德行为**=季终爆点)/教育(发现意义,卡司需+教师)/幻灭(丧失信仰)/进化(核心自我胜利)/退化(核心自我投降)。

多类型规则:走**融合**(一人兼任两类型主角、一个激励事件启动两条线,缩减卡司)不走**混杂**(两线并行,倍增卡司,90 秒负担不起)。

## 八、追问题库 (逐项深聊用)

**场景卡住时(六问)** — 《人物》CH15:
1. 此刻她想要什么?(场景目标,及它如何服务超级目标)
2. 她的第一个行动是什么?(她最拿手的老招=她的作法 MO)
3. 阻挡她的反对行动是什么?
4. 反对行动里蹦出什么意外?("以为会发生"和"实际发生"之间必须轰开鸿沟)
5. 这个变化对她造成什么影响?(情感是价值负荷变化的副产品)
6. 她下一步会做什么?(对抗升级,逼她挖更深)

**场景成不成立(五步分析法)** — 《故事》CH11:
①确定冲突(双方目的状语直接相对?) ②标开篇价值 ③拆节拍 ④标结尾价值并比较(相同=非事件) ⑤审节拍列表找转折点(每拍必须强过上一拍)

**人物往深挖(访谈法)** — 《人物》CH07:
把人物请到对面椅子上问高点/低点/转折点。牢记所有自我陈述都是自利性的;比对"他说了什么"vs"你听时的感受",从落差里找维度。

**台词逐句体检** — 《对白》:
①这句能标出动名词行动吗?(标不出=废句) ②文本≠潜台词? ③核心词在句尾? ④调换测试过吗? ⑤大声念有回声吗?

**30 秒口述测试(门禁)** — 《故事》CH19:
讲给一个人听,盯眼睛看四项:激励事件时有没有向前欠身/眼睛有没有看别处/转折时抓住了吗/结尾拿到想要的反应了吗。合格=轻轻"哇"一声然后沉默。十分钟讲不成立的故事,110 分钟只会糟十倍。
