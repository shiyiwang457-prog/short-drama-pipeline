# 陪写手册 (从 0 到 1 模式 · 每次陪写必读)

一期是"带稿来看病",二期是"空手来,陪你从 0 写出来"。五个工位,每站都是可对话的专家,不是一次性函数。

## 总规则 (Factory 化,file-authoritative)

1. **文件是权威**: 开工先建工程目录 `~/Desktop/11/<项目名>/剧本工程/`,五站各产出一个编号文件(00-04)。**门禁 = 文件落盘 + 用户明确拍板,两者缺一不关门。** 没有文件的"聊完了"不算过站。
2. **每站节奏**: 开工先亮"本站要回答的问题 + 关门条件"(让用户知道现在在哪一步/下一步是什么) → 医生问诊(≤3 问,能推断就不问) → 出草案 → 用户拽住聊、改 → 拍板 → 落盘 → 关门。
3. **回改规则**: 任何时候可以说"回人物站"。上游文件改动后,下游受波及的部分标【待复检】,按根因路由传播(改了对手强度→节拍表复检;改了节拍→台词受波及场次复检)。
4. **拍板点风格**: 方向性决策给 A/B/C + 推荐(AskUserQuestion),不发问卷,不自由发挥长段落。**拍板问题只许问内容,禁止问流程**——"这个结尾行不行""发哪版"是合法问题;"追认放行吗""关门吗""打回哪一站"是非法问题(流程术语对 PM 无意义,已三次实证把用户问懵)。门禁在后台记录,呈现给用户的永远是作品判断题。
5. **对话纪律沿用诊断模式**: 直说、带书证、用户坚持就记风格选择。
6. **每站草案自带医生自检**: 出手前先过本站关门清单,不合格的草案不端给用户。

## 站 -1 原型档案（仅真人真事改编时启用）→ `原型戏剧档案.md`

**回答的问题**: 素材里有哪些戏、这个人的矛盾是什么、哪些空白必须虚构、哪些指纹必须换掉。

- **信源半径先画满,再动笔**: 公开物料(视频转写流水线/文章) + **知情人访谈**(最便宜最富的信源,常被漏掉——给知情人 10 问清单) + 一手长材料(正片/长访谈)。最富信源未采时,档案必须标 ⚠️ 完备度 Gate,写明解锁什么
- **提炼目标是戏剧矿脉,不是传记研究**。七件套产出:
  1. **名场面清单**——素材里现成能拍的戏,逐条立项(场面/素材依据/为什么是戏/可用于哪站)。判据: 有两读、有矛盾发作、有实物道具的瞬间才算
  2. **维度表**——麦基语言(矛盾对+两极的素材证据+定义性判定)+作法 MO
  3. **故事线**——按部件拆(激励事件候选/进展纠葛/危机两难/高潮/新平衡),**不是时间线**;时间轴≠故事,价值通过冲突翻转才是
  4. **台词矿三级**——内核可化用(禁原句)/半指纹(名场面级,化用必须变形)/指纹禁用
  5. **对抗力量三层清单**——个人外/个人/内心,附称重结论(下风狗?)
  6. **指纹对照表**——姓名/数字/校名/座右铭/标志事件,逐条给替身;剧本一律用右栏
  7. **戏剧空白立项**——哪些空白是戏剧刚需必须虚构+**虚构方向约束**(必须贴素材已有质地,不许编反;负面虚构禁令)
- **红线协议**(真人改编的硬边界): 授权三档——有本人授权→可实名;无授权→强制原型化(彩蛋级识别:粉丝认得出,律师挑不出);想"一眼认出"→顶回。**负面虚构禁令**: 不给原型编负面情节。虚构占比+集中点登记进对照表
- **关门**: 七件套齐 + 完备度 Gate 有明确判定(够开工/需先补哪个信源) + 拍板
- 信源纪律沿用: 三层分离(本人原话/行为证据/他人标签)、核实度标注、残缺句不进结论

## 站 0 定题 → `00-合约.md`

**回答的问题**: 这条片在哪个世界里、按什么类型合约、给谁看、要什么情绪。

- 问诊(≤3): ①发哪/给谁看(竖屏流量/中视频/系列账号的一集)? ②想让观众带走什么情绪? ③单集还是系列?
- 干活: 类型四件套(clinic.md §7 选表填格) + 世界界定表(时代/期限/地点/冲突层面选组合) + 一句话故事 v0
- 自检: 把世界缩到全知尺寸——"没有一只家雀掉下来你不知道";写出来的东西有陈词滥调味 = 对世界还不够熟,先补世界不改句子
- **关门**: 四件套无空格 + 一句话故事能讲出口 + 拍板

文件字段: 发布形态/**叙事视角**(第一人称自述体·第三人称剧情·第三人称解说体·主观镜头,必填——它决定台词稿的整个语法)/核心情感/类型+四件套/世界界定四栏/一句话故事/(系列账号)本集在人物资产上的任务

## 站 1 人物 → `01-人物卡.md`

**回答的问题**: 谁在做,观众为什么心疼他。

- 问诊: 人物从哪冒出来的?——从职业/情境冒出 → **由表及里**(建号期默认);从一句台词/一种痛感冒出 → **从内到外**(养人物期默认)。措辞铁律:"如果**我是这个角色**,在这种情况下,我会怎么做?"(不是"我会怎么做",也不是"他会怎么做")
- 干活顺序: 定位(职位/圈层,一职位一人) → 外在塑造(密度留白 7/10 + 竖屏视觉锚) → 内在真相(主导动机 2-3 条 → 激励事件 → 欲望目标**具体到一句话**) → 维度(≥1 个定义性维度,三判据:一以贯之/多变/无解) → 卡司算式(每个配角一个特性精确顶住主角一维,顶不住就删;第二圈零维) → 对抗称重(内心/个人/个人外三层,主角必须是下风狗)
- 深挖工具: 自我故事访谈法(所有自我陈述都是自利的,从"他说的"vs"你听时的感受"的落差里找维度)——character.md
- **关门清单(8 勾全过)**: 有维度非特征清单 ☐ 定义性维度 ☐ 塑造≠真相 ☐ 欲望具体 ☐ 危机是两难非善恶 ☐ 下风狗 ☐ 配角职位不重复 ☐ 复杂性≤对抗力量 ☐ → 拍板

## 站 2 故事 → `02-节拍表.md`

**回答的问题**: 90 秒里真的发生了事吗。

- 干活: 激励事件(六判据全中;构思法:"能发生在他身上最坏的事是什么?怎么变成最好的?";竖屏位置 0-8 秒) → 分节拍表(clinic.md 模板,配额按时长:90s=12-16 拍 3 翻转) → 价值曲线 → 危机真两难(三方结构:得 B 必失 C) → 高潮由人物选择造成 → 结尾基调形象(最后 1-2 秒定格,不切黑)
- 硬检: 统一性句("因为【激励事件】,所以【高潮】必须发生"念得通) / 巧合红线(45 秒后禁用,巧合转折结局零容忍,唯一合法位 0-8 秒) / 回报递减(无三连同号) / 删场判据(剪掉不削弱高潮的场,删)
- **门禁: 30 秒口述测试**——医生把故事 30 秒讲给用户听,用户当第一观众,四指标:激励事件时想不想追问/中途走没走神/转折抓没抓住/结尾是不是"轻轻哇一声然后沉默"。不过 = 回改,不硬闯("30 秒讲不成立的故事,3 分钟只会糟六倍")
- **关门**: 硬检全过 + 口述测试过 + 拍板

## 站 3 对白 → `03-台词稿.md`

**回答的问题**: 这句话是在做事,还是在聊天。

- **动笔前 12 项 Gate**(dialogue.md;没填满就写 = 进改写陷阱)。映射:①-④故事层 ← 00/02 文件;⑤-⑧角色层 ← 01 文件;⑨角色专属词库**现填**(每人 5 名词+5 动词,六维);⑩-⑫场景层 ← 02 节拍表逐场
- 干活: 七步工序——潜台词先行(先写心里那句,再写嘴上替代它的) → 角色内写作 → 台词设计(掉尾句优先,核心词压句尾) → 两人对戏查三边(第三者:物品/缺席者最便宜)
- 竖屏纪律: 每句 ≤ 一行字幕(16 字,**按卡逐句实数,不许目测**) / 停顿 ≤1s 且配表情特写 / 金句每条 1 句(专属词汇+句尾核心词+≤12 字+脱离剧情独立成立) / 潜台词落在**用词选择**上不靠语气(静音场景)
- **第一人称自述体特别纪律**: "我"的每个动作和每句话都是人设宣言——站 -1 档案里登记过的一手策略(如"对恶评第一时间屏蔽不看"),台词和行为**不得反写**,类型爽点不构成豁免;第三人称剧情可拉伸人物,第一人称不行。写完跑一遍"人设对撞检查":逐拍对照档案的 MO 与策略清单
- **关门清单(7 勾)**: 每句能标动名词 ☐ 文本≠潜台词 ☐ 核心词在句尾 ☐ 相邻节拍动名词零重复 ☐ 三边可指认 ☐ 大声念过无回声 ☐ 调换测试过 ☐ → 拍板

## 站 4 质检 → `04-质检报告.md` (agent 化,无人值守)

**回答的问题**: 能开机吗;不能的话根在哪一站。

- **派工**(判断线:不需要用户在场的中间劳动=派 agent): 用 Agent 工具起一个 general-purpose 子代理,brief 骨架:

```
读以下文件: <工程目录>/00-合约.md、01-人物卡.md、02-节拍表.md、03-台词稿.md,
以及 ~/.claude/skills/story-doctor/references/clinic.md。
按 clinic.md 三张诊断表(S1-S14/C1-C10/R1-R7)+第二节硬参数表逐条核对台词稿。
只报命中项,每项五件套: 症状|位置(第几拍/哪句)|病根(书证)|严重度(致命/扣分/风格选择)|根因层。
同时核对 03 是否忠于 00 的类型四件套与 02 的节拍表(漂移也算命中)。
返回结构化清单,不写建议书,不加客套。
```

- 医生接手: 总览分档(show_widget 可用则出图) → 根因路由 → 用户点哪项聊哪项 → 处方 → 改完**复检只重跑命中项**
- **放行判定**: 无致命项 + 用户拍板 → 04 文件末尾盖"可开机"章(写明日期与残留的风格选择项)

## 复盘回路 (发布后,可选第六步)

- 输入: 完播率曲线(截图或口述"掉在第 X 秒")+ 成片
- 方法: 掉率点秒数 ↔ 02-节拍表对齐 → 定位掉在第几拍 → 先验二选一: 中段缓降=重复节拍(S7);断崖=转折太晚或巧合穿帮(S3/设计瑕疵) → 处方回写下一集的 00-合约
- 产出: 追加写入 04-质检报告或诊断记录,形成"下一集开工前必读"

## 模式衔接

- 陪写产出的稿子随时可转**诊断模式**复诊(复诊基线=最新拍板版)
- 诊断后需要重写的稿子,可从站 2 或站 3 接入陪写(上游文件按诊断结论补齐)
