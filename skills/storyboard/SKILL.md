# 分镜剧本工作室 (storyboard)

## 定位

**上游**：story-doctor 出的定稿台本
**本层**：把台本变成**导演可审、提示词层可装配**的分镜表
**下游**：提示词层（逐镜装配成平台文本，**不做任何新的构图判断**）

---

## 三条元规则（每次作业前先读一遍）

### 1 · 决策留在分镜层，不许下放

构图判断（景别 / 机位高度 / 焦距 / 主体位置 / 光位 / 视觉中心 / 眼睛高度 / 元素职务）**必须写进分镜表**，不许留到提示词层再定。

**判据**：如果提示词里出现了分镜表没有的构图判断，说明决策放错了层，**回写分镜表**。

> 实证（2026-08-13《纪念日》）：构图决策被写进了提示词 v3，分镜表还停在"固定·标准"×11。
> 后果不只是不同步——**那些决策绕过了导演审阅**。

### 2 · 卡有适用条件，用卡前必须核

规则库的卡带 `适用景别 / 适用场景类型 / 表演风格档 / 推论字段`。**取卡之后先核这四栏，再核卡的原始语境。**

> 实证：`FRAME-43 用眼睛高度差表现权力关系` 的原始语境是**警长抓逃犯**（权力与征服）。
> 把它套到**恋人托付**的戏上，画面会读成"他在压她"。**卡本身没错，是没读适用条件。**

**动作**：每次引卡，在分镜表里写明「依据 [[卡名]]」，并在有疑问时把卡的原始语境抄一句进理由栏。

### 3 · 先通读全片，再动任何一场

见下方**站 −1 硬门禁**。

> 实证：只读了场 2 与场 16 就定了九个构图决策，通读全片后**三个关键决策里错了两个**。
> 侯寄南原话（[[BODY-43 从剧本挖形体线索的四问]] 失败模式）：「**切忌拿到剧本后，只顾自己将要扮演的角色或几个重场戏**」。

## 规则库接口

**位置**：`~/Desktop/11/_规则库/`

| 要什么 | 去哪 |
|---|---|
| **某一站该用哪些卡** ⭐ | **`_索引/<站名>.md`** —— 每站一页，已含本站卡 ＋ 全部通用卡 |
| 全库的失败模式清单（质检用） | `_质检清单.md`（派生，按站分组） |
| 部件有哪些、可不可见 | `部件清单.md`（六系：气/声/形/关节功能/机体觉/特写级） |
| 现成的 G2 范例（few-shot） | `案例/CASE-*.md` |
| 抽取纪律、卡的字段含义 | `_抽取规范.md` |

### 取卡三步（**不许跳过第 1 步**）

```
1. Read ~/Desktop/11/_规则库/_索引/<站名>.md        ← 一页，1–3 千字
2. 按「适用景别 / 场景 / 失败模式」三栏筛出本镜真正要用的 5–8 张
3. Read 选中的那几张全卡（📖 标记的改读 references/ 里的深度版）
```

**索引行的五栏怎么用**：

| 栏 | 用来 |
|---|---|
| **失败模式** ⭐ | **优先读**——这一栏说的就是「什么时候你会需要它」，**而且它是书上的原话** |
| 适用景别 | **排除**——本镜是全景，就不看「特写/大特写」那些 |
| 人数限制 | **排除**——单人戏不看「多人同场」的 |

⚠️ **失败模式栏优先于适用景别栏。**
`失败模式` 是**书上的话**；`适用景别` 是**我标的推论**，会标错，也覆盖不了「机位」这类不属于景别的维度。

> 实证（场 8，2026-08-14）：[[BODY-45 远景与过肩镜头也不许放松]] 的 `适用景别` 原标 `[全景, 中远景]`，
> **按它会排除场 8 的中景过肩镜**——但同一行的失败模式白纸黑字写着「**远景或过肩镜头**」。
> **根因：「过肩」是机位不是景别，字段装不下。** 已给该卡补 `中景`，但**同类错还会有**。
> **两栏打架时，信书上的那栏。**
| 型 | 必须型/禁止型优先过，量化型给数值 |
| 📖 🔄 | 📖＝有深度蒸馏版；🔄＝可反用 |

⚠️ **筛完要写下排除理由。** 「没想起来」和「看过了不适用」是两回事，
分镜表的「明知而不做」那一节就是记这个的。

> 实证（场 10，2026-08-14）：不用索引时全场只引 7 张站 3 卡，**漏掉了 [[FACE-10 微相不能是全相的重复]]**——
> 而场 10 犯的错正是把「屏幕半与现实半要匹配」扩大成「7 镜同机位同景别」。**卡就在库里，没被想起来。**

**索引是派生的**，新扫的卡自动进，不会变孤儿。重算：`python3 ~/Desktop/11/_规则库/_重算索引.py`

⚠️ **规则库是唯一知识来源。** 任何构图或表演判断都必须能指到一张卡；指不到的，在分镜表里**显式标注「无书本依据·工程判断」**，不许混进来假装有据。

## 十站流水线

每站**文件落盘**才算关门。文件路径：`<项目目录>/剧本工程/`

### 🚪 站 −1 · 全片通读（**硬门禁**）

读**完整台本 + 导演注记 + 人物卡**，产出《全片约束表》。

| 产出栏 | 内容 |
|---|---|
| 全片一句话 | 这片子在讲什么 |
| **⭐ 观看语境** | **载体 / 发法 / 屏幕 / 起播有没有声 / 成功标准 / 片长在该平台算长还是短**（见下） |
| **逐场戏核** | 每场一句「不是〈平铺直叙版〉，而是〈加了限定版〉」（[[FRAME-42 先定戏核再定画面]]） |
| **跨场回扣** | 哪一场埋、哪一场收 |
| **全片名额** | 某手法只准用在哪几场（如二分法留给闪回/转场） |
| **全片禁令** | 导演注记里的「不许」 |
| **人物弧线** | 每人的体积档/速度档/显隐档在各阶段的取值 ＋ 拐点（[[BODY-42 人物外部特征的变化总谱]]） |

**门禁**：`ls` 得出 `全片约束表.md`，**且表内含「观看语境」栏**，否则不许进站 0。

#### ⭐ 观看语境栏（**2026-08-14 立**）

规则库的卡**全部来自影院／舞台／纸质图像小说**，假设的观众是**坐着、看完、有声、大屏**。
**不填这一栏，就等于默认按影院观众做取舍。**

| 必填 | 它定什么 |
|---|---|
| 载体（信息流／点播／私下发给人看） | 观众能不能划走 |
| 发法（完整一条／切片） | 跨场回扣还有没有效 |
| 屏幕 | 全景还有没有信息量 |
| **起播有没有声** | 前 3 秒能不能依赖台词与音效 |
| **成功标准**（完播率 vs 打动人） | **所有阈值往哪边调** |
| 片长在该平台算长还是短 | 要不要设计留人点 |

**填完必须写出「哪些书上的阈值被覆盖了」**，逐条标 D（无书本依据·工程判断）。

⚠️ **覆盖 ≠ 推翻卡。** 卡在它自己的语境里仍然成立，冲突的根因是语境不同。

> 实证（《纪念日》2026-08-14）：确认发抖音＋数据导向后，五条书上阈值被覆盖
> （蓄力镜时长／特写占比／留白总额／停顿时长／建环境用不用全景），
> 并连带触发两场已定分镜的改判。**这一栏不填，那两场会照着影院节奏做完。**

**⭐ 拍板点 1**：把《全片约束表》给用户看，确认后才往下走。

### 站 0 · 形体卡（每个有名字的人物一张，配角也要）

取卡：`站0-形体卡` ＋ 通用

必答四问（[[BODY-43 从剧本挖形体线索的四问]]）：
① 他究竟是个什么样的人 ② 哪些特征使他成为某一类人的代表 ③ 生活经历在他形体上留下哪些印记 ④ 他习惯以什么方式和节奏动作

**必填栏**：

| 栏 | 依据 |
|---|---|
| 全形（一句话总体轮廓） | [[BODY-39 全形先于细部]]——**配角也要有，只是简练** |
| 类锚 ＋ 至少一条个性偏离 | [[BODY-38 典型是类的特征加个性]]——只写类锚＝主动请求模型给平均值 |
| 六项站走参数（重心高度/两脚间距/膝角/着地方式/上体倾角/左右晃动） | [[BODY-27 站走特征的四类成因]] |
| 气质三轴（强弱/快慢/显隐） | [[BODY-37 气质四型与三个反应轴]] |
| 体积档（胀大/常态/缩小） | [[BODY-30 自我感觉的胀大与缩小]] |
| **识别锚**（各角度、各布光下都认得出的一样东西） | [[FRAME-24 跨镜识别锚]]——优先选**剪影可辨**的 |
| 基调压缩词（动物名或单字） | [[BODY-34 动物摹拟压缩人物形体]] ⚠️ **只停在形体卡，不许进提示词** |

#### 🚪 站 0 门禁（**2026-08-14 立** · 两条判据都要过）

| 判据 | 怎么验 | 出处 |
|---|---|---|
| **① 数量足额** | 形体卡里的人物数 **==** 台本里有名字的人物数。**配角一个都不许少**。<br>验法：`grep -oE "^> \*\*[^*]+\*\*" 台本.md \| sort -u` 数出来，与形体卡的人物节数比对 | [[BODY-39 全形先于细部]]：「**即使你扮演的是一个非主要角色**……也应当用同样的方法，简练地、明确地为人物勾画出全形」 |
| **①b 不入画的也要立条目** | 只有画外音的角色**同样占一节**，但写的是**音色规格**（年龄段／语气／语速／录音质感／提示词写法）而非体态。<br>**「不入画」必须写成一个带理由的决定，不许省略** | 平台会生成对白人声（`_模型档案-Seedance.md`）——**画外角色有声音就有规格**。<br>退出视觉中心的极端档见 [[FRAME-16 让次要人物退出视觉中心的五种手段]] |
| **② 必填栏无空缺** | 七个必填栏（全形／类锚＋偏离／六项站走／气质三轴／体积档／识别锚／基调压缩词）**每人每栏都有值**，不许留「待定」 | [[BODY-33 形体模型必须清晰]]：「**形象模糊的模型，是无法达到准确控制的**」 |

⚠️ **判据 ① 最容易漏的是配角。** 主角的形体卡不会忘，配角的会——
而 BODY-39 明说配角也要有，只是「**简练**」，不是「可以没有」。

**⭐ 拍板点 2**：形体卡给用户看。

### 🚪 站 1 · 场景卡（**硬门禁**）

取卡：`站1-场景卡` ＋ 通用

⭐ **按空间组织，不按场次组织。** 一个空间被 N 场共用 ＝ **一张卡**，不是 N 张。

| 栏 | 依据 |
|---|---|
| 客观条件（地点/时间/天气/光源） | — |
| **这个背景在说什么**（稳定/不确定/不祥/中性） | [[FRAME-06 背景会说话]]——不能只写"是什么" |
| 四组对比轴（有序⟷无序 · 复杂⟷简单 · 大⟷小 · 正⟷负空间）各拨到哪档 | [[FRAME-15 构图的四组对比轴]] |
| 主导趋势线（水平/垂直/对角/曲线）＋ 由什么承载 | [[FRAME-14 趋势线的情绪映射]] · [[CASE-07 引导线的六种载体]] |
| 日/夜的做法（**夜景靠反射光不靠调暗天空**） | [[FRAME-07 日景夜景靠反射光区分]] |
| 环境物件清单 ＋ **每件在哪一层、亮还是暗** | [[FRAME-44 正确的构图分区无畏杂乱]] |
| ⭐ **固定拍摄点位表** | 复用空间必备：每个点位的机位／光／**必然入画的东西** |
| ⭐ **逐场分配表** | 哪一场用哪个点位 |

**门禁三条判据**（缺一不许进站 2）：

1. **`ls` 得出场景卡文件**，且**片中出现的每个空间都有一条**（不是每场一张——共用空间合并）
2. **被 2 场以上共用的空间**，必须有 **固定拍摄点位表** ＋ **逐场分配表**
3. **每个点位写明「画面里必然有的东西」**——这是提示词层「场景环境」段的原料

> 🔴 **实证（2026-08-14，《纪念日》16 场做完后才发现）**：
> 站 −1 与站 0 有硬门禁，都做了；**站 1 当时没有门禁，于是 15 场整站漏掉**，只剩早期做的 1 张。
> 一路走到提示词表 v2 才暴露：
>
> | 症状 | 规模 |
> |---|---|
> | 出租屋 **10 场共用**，提示词里只有「白天的出租屋，窗光平而亮」 | 11 块——**模型会造 11 个不同的房间** |
> | 完全没有站位描述 | 6 块 |
> | 「这个背景在说什么」从未判断 | 全片 |
>
> ⭐ **教训**：**没有门禁的站会被跳过，而且要到下游才暴露。**
> 判据不能是「我做了吗」，必须是 **`ls` 得出文件 ＋ 数量对得上空间数**。

**⭐ 拍板点 2.5**：共用空间的**布局与跨场硬约束**要给用户拍板——
「这两场是不是同一面镜子」「这两场是不是同一个抽屉」这类问题**决定回扣成不成立**，
不是美术细节，**是叙事决策**。

### 站 2 · 拆镜

工程规则（**非书本，标 D**）：台词按 **3.5–4 字/秒**换算；无台词场按**画面事件数**分配。

**平台参数写在项目里，不写在 skill 里。** 开工前先查项目的《全片约束表》或模型档案，拿到三个数：

```
单块时长下限 ＿＿ 秒   ← ⭐ 通常比上限要紧得多
单块时长上限 ＿＿ 秒
画幅默认值 ＿＿       ← 与项目画幅不符时，每条提示词都要显式改
```

> 实测参考（《纪念日》· Seedance 2.5 第三方包装 · 2026-08-14）：**4 – 30 秒**，默认 16:9。

#### 🔢 开工第一步 · 检查一：**台词装不装得下**（**每场必做，先于块划分**）

```
台词秒数   = 全场台词字数 ÷ 3.5~4      （只数汉字，标点不算；快问快答段可按 4.6）
画面事件数 = 台本里能数出的独立视觉动作／变化的个数
画面秒数   = 无台词的那些画面事件 × 0.6~0.9 秒
需要时长   = 台词秒数 + 画面秒数
盈亏       = 场时长 − 需要时长
```

⚠️ **必须两项都算。只算台词会漏掉「事件密集场」**（2026-08-14 场 5 实证）：

> 场 5 台词仅 12 字（3.4″），按只算台词的口径是「余 8.6″，充裕」——
> **但它要在里面装两个地点共 13 个画面事件，实需 11.5″。**
> 我据此从它身上匀走了 2 秒，**把一个本来就紧的场压成了装不下**。
> 同一个盲区盖住场 13（14 个事件）、场 14（11 个）、场 15（8 个）——**全是 0 台词，全被标成"充裕"**。

**判据：0 台词或少台词的场，一律按画面事件数重算，不许直接看余量表。**

⚠️ **两个只会犯一次的错**（2026-08-14 当场踩中，已改）：
1. **标点不算字**——「两束。」是 **2 字**不是 3 字。全场累积能差出 20%
2. **台词是盖在画面上的**，不另占时间。**只有无台词的段落**（停顿、纯画面、切换）才单独计秒。
   把两者相加＝双重扣减，会把「紧」误判成「装不下」

| 盈亏 | 判定 | 动作 |
|---|---|---|
| ≥ +2″ | ✅ 够用 | 继续 |
| 0 ~ +2″ | 🟡 紧 | 继续，但**所有停顿要精确到 0.5 秒** |
| **< 0** | 🔴 **装不下** | ⚠️ **立即回报上游，并在分镜表里给三条路**：①砍哪几句台词（写明代价）②本场加时长、从哪几场匀 ③按超时版本出表，等拍板 |

⚠️ **砍台词的净收益要打折**（2026-08-14 场 9 实证）：
一句台词**同时也在给它底下的画面提供时长覆盖**。砍掉之后，那几拍变成纯画面，**反而要单独占时间**。

```
净省 = 台词秒数 − 失去覆盖的画面所需秒数
```

> 场 9 砍掉 16 字（预期省 4.6″），但那句盖着「花移开 → 她的脸 → 镜头推进」三拍，
> 这三拍改成纯画面要 1.5″ → **实际净省 3.1″，余量从预期 0.5″ 变成 0″**。

**判据：砍之前先问「这句底下的画面，没有台词还站得住吗」。** 站不住 ＝ 砍了要还。

⚠️ **分镜层只报告，不自己改台本。** 但**必须算**——不算就会在提示词层才发现，那时候已经排完了。

> **实证（2026-08-14，两场连续踩中）**：
> 场 1：49 字 ＋ 运镜停顿 ＝ **需 20″，台本给 18″**（超 2″）
> 场 11：**57 字 ＝ 光台词就 14.3–16.3″，而台本只给 14″**——**画面一秒不剩**，实需 21″（超 7″）
> **规律：台词密集场必超。** 场 2（34 字/10″）、场 10（16 字/13″）、场 16（0 字/23″）都不超。
> **这个检查必须先于块划分**——块数是按场时长算的，而场时长本身可能就是错的。

#### 🧭 ⭐ 块边界的机械判据（**2026-08-14 立 · 先于检查二**）

**逐镜表必须有三栏独立成列**，不许混在画面描述里：

| 栏 | 取值 | 它管什么 |
|---|---|---|
| **地点** | 海边／出租屋／医院… | 空间跳转 |
| **时间** | 清晨／白天／黄昏／夜 | 时段变化 |
| ⭐ **轨道** | **只标摄影机输出的画质**：正常／DV／取景框 | **画质切换** |

⚠️ **「画面里有一块屏幕」不是轨道，是画面内容。**
摄影机拍一个人对着电视，**画质仍然是"正常"**——屏幕里放什么是另一层。

> 实证（2026-08-14）：我第一版总表把「屏内」也当成一种轨道，
> 结果**场 13 镜 8→9 被误报成"遗漏的画质切换"**——实际那里画质没变（正常→正常），
> 变的是构图（屏幕从画面里消失），**而且它早已是块间缝**。
> ⭐ **轨道栏混进构图信息，就会造出假的块边界。**

```
块边界 = 这三栏里任意一栏发生变化的地方
例外   = 若该缝有自然的遮挡转场，可合并
```

⭐ **有了这三栏，块划分是读出来的，不是判断出来的。**

> **为什么要立**：2026-08-14 对照一份外部分镜表（《倒带》）发现——**它把地点、时间、"DV视角"各自独立成栏**，
> 而我们把这些混在画面描述里。结果：《纪念日》场 16 块 B 内藏着 **3 次画质切换**，
> **我是读到"【取景框视角】"这几个字才发现的**——读漏就整块做不了。
> **判据不该依赖"我记得"。**

> ⚠️ 例外的实证：场 5 山路 → 山顶（地点变），**但台本的「镜头抬起来，对准山脊」本身就是一次遮挡转场** → 可合并。

#### 🔢 检查二：**块合规性**（⚠️ 不是"块经济性"）

```
块的切点由叙事断点决定（画质切换 / 空间跳转 / 台本明写的「——切」）
但每一块必须满足：下限 ≤ 块时长 ≤ 上限
```

⭐ **顺序很重要：先按叙事切，再检查每块合不合规。** 反过来（先按时长均分）会把切点切在戏中间。

| 块时长 | 判定 | 动作 |
|---|---|---|
| **< 下限** | 🔴 **不能生成** | 三条路，见下 |
| 下限 ~ 上限 | ✅ | — |
| **> 上限** | 🔴 | 再切一刀，**切点选画面静止的瞬间**（[[BODY-21 速度节奏是动作的标点]]：标点处是最好的接缝） |

**短块的三条路**（按优先级）：

| # | 做法 | 前提 | 代价 |
|---|---|---|---|
| **1** ⭐ | **与相邻块合并** | **那个缝能用遮挡转场**（平台禁硬切） | 最省。⚠️ **画质切换能不能当块内缝，要实测** |
| **2** ⭐ | **把内容拉长到下限** | **戏核允许变慢** | 有时**反而更好**——2 秒的静止拉到 4 秒会更狠 |
| **3** | **改设计** | — | 最贵，但有时是唯一解 |

> 🔴 **实证（《纪念日》2026-08-14，拿到平台数字当天）**：
> 按叙事断点切出 **32 块**，对照下限 4 秒 —— **12 块违规，涉及 5 场**。
> **每个违规块的解法都是"合并"，而每次合并都要跨一个叙事断点** —— 这就和"禁硬切"撞上了。
>
> **由此逼出的一条判定**：场 2 六镜正反打每镜 1–1.5 秒，**怎么合并都躲不开块内硬切** →
> **4 秒下限直接判定这场必须改成双人同框长镜**。
> ⭐ **下限不是成本问题，是设计约束。**

⚠️ **不要在 skill 里写死具体秒数。** 平台参数写进项目的《全片约束表》或模型档案，
**skill 只保留"要检查下限和上限"这条纪律**——**换平台就换数字，换不了纪律。**

#### ✂️ ⭐ 检查三：**剪辑密度**（**观看语境＝数据导向时必做**，2026-08-14 立）

**做完全片才能算，所以它在站 7 之后回头做一次。**

**⚠️ 要算两个数，而且第二个才是判据。**

```
① 剪辑密度   = 全片时长 ÷ (刀数 + 1)        刀 = 块间缝 + 块内遮挡转场
② 画面变化密度 = 全片时长 ÷ 段数            ⭐ 段 = 每一次可见的画面变化（含运镜）
```

| 指标 | 观众感受到的是什么 | 信息流＋数据导向的参考区间 |
|---|---|---|
| ① 剪辑密度 | **剪辑节奏**（后期看到的） | 参考，不是判据 |
| ⭐ **② 画面变化密度** | **画面多久换一次**（观众看到的） | **2–5 秒一变** |

🔴 **判据是 ②，不是 ①。**
**运镜产生的画面变化，观众感受上和切镜是一样的，甚至更流畅。**
一个 18 秒的手持长镜，内部若有 9 次可见变化，**观众体验到的是 2 秒一变，不是 18 秒一刀**。

> 🔴 **实证（2026-08-14，我自己先用错了指标）**：
> 对照外部分镜表《倒带》，先按 ① 算 —— 我们 **11.8 秒一刀** vs 它 **2.0 秒一刀**，差 6.7 倍，
> 据此判定"我们切太慢"，还列了三场要加刀。
> **改按 ② 算：我们 117 段 / 177.5″ ＝ 1.52 秒一变，比《倒带》还快。**
> 七场一镜到底的场，内部全部在 **1.0–2.0 秒**变一次。**"加刀"那条待办当场作废。**
>
> ⭐ **教训：指标选错，结论会完全反过来。** 用"刀数"衡量节奏，等于假设只有切镜才算变化——
> **而手持、摇镜、推拉、光变、屏幕内容变，每一样都是变化。**

🔴 **平台约束（禁硬切、时长下限）会压低 ①，但基本不影响 ②。**
→ **一镜到底不等于慢。** 但仍要逐场标明：这一场不切，是**叙事选择**还是**平台所迫**。

| 要做的 | 依据 |
|---|---|
| 先列**情感线**，再列**物理表达**（双轨表） | [[FRAME-42 先定戏核再定画面]] |
| 块缝落在哪（视线连接的两镜**必须同块**） | [[BODY-31 分切拍摄必须有跨镜连贯的载体]] |
| ⭐ **每个人的进出场**：他从哪来、怎么进画、从哪走 | 平台禁「对象凭空出现」（官A）——**只写动作不写进场＝模型自己编** |
| ⭐ **摄影机换手／视角转移的物理证据** | 有一次就**每次都要有**，证据必须对称 |

> 🔴 **实证（2026-08-14《纪念日》场 1）**：改结构时最容易掉的就是这一栏。
> 台本本来写着「镜头转过来，对准他」「他走进画面」，v2 加了「DV 换手」之后，
> **动作继承下来了，进出场逻辑没有**——2 秒的浪画面之后两个人同时凭空出现。
> **上游一改结构，被改那几段的进出场要重走一遍。**
| **⭐ 每个镜缝定「切点类型」** | **平台禁止硬切**，见下 |

#### 🔪 切点类型（**2026-08-14 立**）

平台原文：**「不支持硬切换和对象凭空出现」**，块内切点要用**遮挡转场**（`_模型档案-Seedance.md`）。

→ **每个镜缝必须标成三类之一**：

| 类型 | 什么时候用 | 怎么写 |
|---|---|---|
| **块间缝** | 两镜分属不同生成块 | **自由**——切点交给后期，平台管不着。**要硬切就走这条** |
| **块内·遮挡转场** | 同块内，且平台认可 | 前景物件划过 · 身体挡镜 · 光影覆盖 · 画质由粗糙变干净 |
| **块内·硬切** | ⚠️ **平台禁止** | **不许用**。真需要硬切 → 把这个缝改成块间缝 |

⚠️ **这条会反向约束块划分，而且是双向的**：

| 情形 | 后果 |
|---|---|
| 有**叙事上必须硬切**的缝 | 那个缝**只能是块间缝**——哪怕单块时长装得下整场 |
| **一镜到底、一个缝都没有** ⭐ | **块间缝是纯损失**。此时块划分**只由时长上限决定**，且**切点要选在画面静止的瞬间**（[[BODY-21 速度节奏是动作的标点]]：停顿是标点，标点处也是最好的接缝） |

**先判断这一场有没有叙事缝，再谈块怎么划。**
一场戏若一个镜缝都没有，「拆镜」这一站产出的是**段**（运镜段落）而不是**镜**——
逐镜表照写，但「切点类型」栏全部是「无缝（运镜）」。

> 实证（场 10）：镜 3→镜 5 是【屏幕】→现实的切换，注记二要求靠画质区分、不许有缓冲。
> **这个缝必须硬切 → 必须落在块间。** 若为了省积分把 13 秒装成一块，这个缝就会被平台加上过渡，**戏就坏了**。
| 一致性锚：光/服装/**情绪档/速度节奏档**/识别锚/视觉中心位置/轴线方向 | BODY-31 明说要锁「心境·感觉·节奏·动作」四项，**只锁外形不够** |
| 高潮前插一个**中立镜蓄力** | [[FRAME-26 高潮前要有一个中立镜头蓄力]] |
| 变化总谱：本场在人物弧线的哪一段 | [[BODY-42 人物外部特征的变化总谱]] |

| **有依据地排除的** | 卡名 ＋ **靠索引哪一栏排除**（适用景别 / 人数限制 / 🚧前置条件） |
| **由此触发的改判** | 原来定的 → 改成什么 → 被哪张卡推翻 |

**为什么必含**：它把「**没想起来**」和「**看过了不适用**」区分开——
前者是失职，后者是判断。**不写这一栏，两者在成品里长得一模一样。**

> 实证（场 10 v1→v2）：引卡 13→20 张，**索引捞出 8 张漏卡、有依据排除 6 类、触发 9 处改判**。
> 其中两次是索引**纠正了我**：BODY-45 被待办点名要用，但它 `适用景别: 全景/中远景`，本场无远景镜；
> BODY-30 让我发现**形体卡定的体积档拐点，在本场的中近景下根本看不见**。

**⭐ 拍板点 3**：分镜表给用户/导演看。**这是本 skill 的交付物。**
