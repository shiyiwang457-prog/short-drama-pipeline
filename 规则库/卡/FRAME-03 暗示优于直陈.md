# FRAME-03 · 暗示优于直陈：给答案的同时提出新问题

## 规则
**不要"告诉"，要让观众"感受"。** 具体手段是**留白**——用阴影、静默这类最简朴的语言，而不是堆细节。
判据：**给出一个答案时，同时抛出一个新问题。**

## 我的判断
- **【B ⭐ 这给了「静止清单」一个叙事理由】** G2 的第②件（明确列出哪些部件不动）此前的理由是工程性的（防止模型乱动）。本条给了**叙事理由**：不动的部分就是留白，**留白是观众参与的入口**。
- **【C ⭐ 与生成模型的默认倾向正相反】** 模型倾向于**把画面填满**——细节多、元素多、动作多。本条要求的恰恰是**减**。所以留白必须**显式写出来**（"此外全部静止"、"画面里没有其他东西在动"），不能指望模型自己克制。
  → 《纪念日》场 16 v2 每一镜都写了「除……外全身没有其他动作」，方向是对的。
- **【C · "阴影与静默"两个词很准】** 书点名的两个留白手段正好对应本流水线的两栏：**阴影 → 站5 光色**（见 [[FRAME-01 布光决定给多少信息]]）；**静默 → G2-②静止清单**。
- **【C · 判据可用于站8 质检】** 每场问一句：**这场给了观众什么新问题？** 答不出来，说明全说完了，观众没有参与空间。
