# FRAME-35 · 动势的拐点：变化本身就是张力 ⭐⭐

## 规则
一个镜头的动势不该是一条匀速直线。**在中间放一个拐点**——能量从一种走向突然变成另一种，**变化本身就是戏剧张力**。

## 我的判断
- **【C ⭐ "有目的的动作"与 [[BODY-35 性格表现在怎么做]] 是跨书同一条】** 侯寄南引恩格斯讲**性格**在"怎么做"里；本书讲**动势形状**由目的决定。两本书都在说：**同一个物理动作，有没有目的，出来完全不同。**
  → 写提示词的直接后果：**不写"他抬起手腕"，写"他抬起手腕看表，发现迟到了"**。目的写出来，动作的质地才对。
- **【B ⭐ "2 形动势"是一个可复用的模板】** 跟随 → 抓住 → 下沉到大腿 → 反方向甩出。**这是一个带拐点的完整动作单元**，可直接用在需要"发力"的镜头。
- **【C · 拐点在竖幅的位置有讲究】** 书给了两个选择：**放下半部**（上方留出空间）或**放正中**（上下都有展开余地）。→ 竖屏 9:16 上下空间大，**拐点位置是可调参数**，与 [[FRAME-32 橡皮筋：关键点距离决定张力]] 的地平线高度一起构成竖幅的两个纵向旋钮。
- **【C · 与 [[FRAME-26 高潮前要有一个中立镜头蓄力]] 的层级差别】** FRAME-26 是**镜头之间**的蓄力（插一个中立镜）；本卡是**单镜头之内**的拐点。**两个层级都要有变化**，否则一场戏要么全平要么全躁。
