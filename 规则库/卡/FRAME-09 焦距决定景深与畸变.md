# FRAME-09 · 焦距：同一个景别，两个世界 ⭐

## 规则
**景别管"人在画面里多大"，焦距管"人和背景是什么关系"。** 两者独立，必须分别写。

## 我的判断
- **【B ⭐ 提示词里"标准镜头"这个词一直在偷懒】** 《纪念日》场 16 每一镜都写「标准镜头」，等于全片放弃了这一维。按本条，**至少要在三处做选择**：
  | 想要 | 焦距 |
  |---|---|
  | 人被环境吞没、背景压过来 | **长焦**（景深压缩，人贴在背景上） |
  | 人从环境里凸出来、空间开阔 | **广角**（景深大，纵深强） |
  | 中性、像人眼 | 标头 |
- **【C · 广角有代价】** 极致广角会**让脸严重失真**。所以广角适合**远景/全景/环境**，**不适合近景人脸**——除非要的就是那个失真张力。
- **【C · C-2 那条对本流水线特别有用】** 长焦拍脸 → **背景只剩一小块**。这是一个**低成本的背景简化手段**：不用描述复杂环境，用长焦把它挤掉。省提示词字数，也降低模型画错背景的风险。

## 失败模式
只写景别不写焦距 → **人与背景的距离关系由模型随机决定**，同一场戏里跨镜不一致。
