# FRAME-31 · 纵深感靠三条线索堆出来 ⭐

## 规则
**光靠"有前景中景背景"不产生纵深。** 三层之间必须有**可见的递变**，否则会"贴在一起"。

## 我的判断
- **【B ⭐ 三条线索可直接写进提示词】**
  | 线索 | 写法 |
  |---|---|
  | **明暗递变** | 「前景是**纯黑的剪影**，中景有细节，最远处是画面里**最亮的**区域」 |
  | **细节密度递减** | 「越远的地方**细节越少**」 |
  | **纹理模糊递增** | 「远处的纹理**逐渐模糊不清**」 |
- **【C ⭐ 竖屏尤其需要这条】** 9:16 的横向空间窄，**只能靠纵深撑开画面**。场 16 分镜表当时写「用纵深表现"一排"：近处几朵花合焦，花枝沿石堤往画面深处延伸并逐渐虚化」——**方向对，但只用了虚化一条线索**，明暗递变和细节密度递减都没写。
- **【C · 前景剪影是最省事的一条】** 一个纯黑的前景物（树干、栏杆、花枝）**同时干三件事**：①建立第一层 ②切割画面制造构图 ③挡掉不想给的信息（[[FRAME-01 布光决定给多少信息]]）。**成本是一句话。**
- **【C · 与 [[FRAME-09 焦距决定景深与畸变]] 的关系】** FI-1 讲**长焦会压缩景深让人贴在背景上**（光学原因）；本卡讲**没有景深线索也会贴在一起**（构图原因）。**两个不同成因，同一个结果**——所以要同时防。

## 失败模式
> **前景、中景与背景混为一谈，彼此看上去离得太近以至于仿佛贴在了一起**
