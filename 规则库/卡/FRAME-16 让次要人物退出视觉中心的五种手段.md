# FRAME-16 · 让次要人物退出视觉中心的五种手段 ⭐⭐

## 规则
多人画面里，**不抢戏是要主动做出来的**，不是默认状态。书在三处给了五种手段。

## 书上怎么说

## 我的判断
- **【C ⭐ 五种手段按成本排序，AI 场景下推荐顺序】**
  | 手段 | 提示词写法 | 可靠性 |
  |---|---|---|
  | 卡出画外 | 直接不写这个人 | **最高** |
  | 置于暗部 | "他在暗部，看不清面部" | 高 |
  | 头转开 | "他背对／侧对镜头" | 高 |
  | 遮脸（帽子/前景遮挡） | "他的脸被帽檐遮住" | 中 |
  | 视线不看镜头 | "背景中的人没有看向镜头" | **待测** |
- **【C ⭐ 第④条必须进负向提示词】** 生成模型让背景人物看镜头是**高发问题**——训练数据里大量照片是被摄者看镜头。这条与 [[FRAME-10 避免重叠与奇怪的巧合]] 同属"模型默认输出需显式压制"。
- **【C · 与 [[FACE-09 群戏中每人都有独立反应]] 不矛盾】** FACE-09 说每个人都要单独写反应；本卡说**次要人物的"反应"就是不抢戏**。两条合起来：**每个人都要写，但写法分主次**——主要听者写到部件级，次要人物写"朝向 + 是否在暗部 + 不看镜头"。
- **【C · 第③条是个漂亮的正向用法】** 不是让所有人消失，而是**让所有人朝同一个方向，唯一那个反方向的就是重点**。零成本，且比打光更稳。

## 失败模式
> **群众演员绝不能望向镜头**，否则会**把观众的注意力从女主角身上分散开**
