# FACE-04 · 眼神映射关系与地位 ⭐⭐

## 规则
**看不看、看多久、什么时候看**——由**关系亲疏**和**地位高低**决定，不由情绪单独决定。
这是双人对话戏里最可写、最省字的一栏。

## 书上怎么说

## 我的判断
- **【B ⭐ 这是「听者反应」的书本依据】** 此前方案 §4 的"听者反应"只有工程直觉，没有依据。本条给出了**由关系与地位直接推导的听者眼神规则**：
  | 听者相对说话人 | 听时的眼神 |
  |---|---|
  | 地位低 | **平时不敢直视，只在听他说话时才把目光投向对方** |
  | 地位高 | 居高临下直视，**或根本不看** |
  | 关系融洽 | 对视较多 |
  | 关系生疏 | 较少看对方 |
- **【C · 可提示化程度极高】** "看/不看/听时才看"是四个字能写清、模型也能执行的指令，比"表情复杂"有效得多。
- **【C · 与 [[BODY-24 眼睛不仅表达情绪还能行动]] 配套】** BODY-24 说眼睛能行动（试探/阻止/寻找），本卡说**行动的方向与频率由关系决定**。两者合起来，眼神栏应写三项：**看谁 · 看多久 · 在做什么**。
- **【C · 反用价值高】** 地位低者反常地直视 → 挑衅／摊牌；关系亲密者反常地回避对视 → 隐瞒／愧疚。**眼神是全片最容易做"反常即事件"的部件。**
- **【C · 文化差异是可用的设定项】** 日本场景的对话戏，视线落点应写"胸部或脖子"而不是眼睛。

## 失败模式
> 在形体动作语言中，**切不可轻视眼神的作用**。
