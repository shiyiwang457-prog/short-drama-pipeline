# FRAME-40 · 竖幅双人戏的三种做法 ⭐⭐⭐

## 规则
竖幅左右窄，两个人并排就挤。书给了三种解法，**每一种都把"并排"改成了别的关系**。

## 书上怎么说

> 本卡的「规则」与「失败模式」是对该处内容的提炼与再表述。


## 我的判断
- **【B ⭐ 三种做法各自适用的关系】**
  | 做法 | 表达的关系 |
  |---|---|
  | 垂直物隔离 | **对立、隔阂**——两人同框但被分开 |
  | 拉伸成上下 | **地位差**（呼应 [[FRAME-36 换画幅的三种改法]]：竖幅擅长表现等级差别） |
  | 长焦叠在一起 | **纠缠、共处一境**——距离被消除 |
- **【C ⭐ 对《纪念日》场 2 直接可用】** 场 2 是出租屋双人对话，前半平等、「你有包」之后她被驳住：
  - 前半：两人同框，**不加隔离物**（配置 1，见 [[FRAME-11 双人构图的四组变量]]）
  - 「你有包」之后：**可用做法二**——她的位置略降、他略高，把"被驳住"写成竖向的地位差
  - 镜 6（她一人入画 + 画外音）：**做法三的变体**——去掉环境，只留她的脸
  → 现有的场 2 提示词全是"近景·固定机位·标准镜头"，**三种做法一种都没用**。
- **【C ⭐ 「机位放在被看的物件位置」是个漂亮的手法】** 航海图那例：摄影机**就是航海图**。→ 场 2 里，「他」的画外音那一镜，机位可以放在**他的位置**，让她直接对着镜头说——这是 [[FACE-04 眼神映射关系与地位]] 的最强用法。
- **【C · "作假"是被允许的】** 书直说甲板高度**可以作假**以便靠近角色。→ 我们写提示词时同理：**空间的物理准确性让位于表演的可见性**。

## 失败模式
竖幅双人戏**并排挤在一起**，既看不清关系也看不清表情。
