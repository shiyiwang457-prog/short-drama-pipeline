# BODY-39 · 全形先于细部（配角也要有全形）⭐

## 规则
**先定整体轮廓，再写局部特征。** 顺序反了，细部就没有附着点。
**配角同样要有全形**——这是本条最反直觉的部分。

## 我的判断
- **【B ⭐ 这是站0 必须先于站6 的书本依据】** 分镜 skill 的站序（先形体卡，后逐镜可见状态）此前是流程设计。本条给出依据：**没有全形，每一镜的局部描写就没有附着点，人物会在镜与镜之间散架。**
- **【C ⭐ 配角也要形体卡】** 这是最容易被省掉的一步。短剧里配角常常只有一两句台词，**但书明说"即使是非主要角色也应当用同样的方法"**——只是"简练地"。
  → 建议：主角写完整形体卡，配角写**简版全形**（一行：体积档 + 气质三轴 + 一个动物或单字基调）。
- **【C】** 与 [[BODY-33 形体模型必须清晰]] 是两件事：BODY-33 管**模型够不够具体**，本卡管**先做哪一步**。
