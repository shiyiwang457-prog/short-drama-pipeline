# BODY-29 · 表里可以矛盾：外形不是内心的翻译

## 规则
**外形与内心不是一一对应的。** 写 G2 时必须先答一个问题：**这个人此刻是在"露"还是在"藏"？**
露 → 外形＝内心；藏 → 外形是内心的**反面或掩饰**。这两种写法的部件描述完全不同。

## 我的判断
- **【C · 母题，跨源四处】** 这个母题在本书至少三处出现（p.59 表里矛盾 / p.80-81 形与神 / 罗丹"美就是性格和表现"引文），**并且与麦基的「塑造 vs 真相」是同一个问题的两套语言**：麦基说人物的表层性格化特征与真相在压力下才分离，侯寄南说外部形态与内心世界有时矛盾着。
- **【C · 对 G2 的操作后果】** 这是**站2 人物卡必须补的一栏**：每个人物在每场戏里的"露/藏"状态。
  - **露**：情绪 → 部件（按 BODY-14 心理→站走对照表直接查）
  - **藏**：情绪 → **被压住的部件**（哪个部件在用力不动）＋ **泄漏的部件**（哪个部件没压住）
  - 藏的写法必须点名"哪里在漏"——**只写"表面平静"是 G0，写"手指在桌沿下反复搓" 才是 G2**。
- **【C】** 与 [[BODY-25 基本法则可以反用]] 同构，但不是一回事：BODY-25 是"规则可以故意违反"，本卡是"外形本来就不必等于内心"。前者是手法，后者是事实。

## 失败模式
把外形当成内心的直接翻译，一一对应地写。**结果是所有人都表里如一，全片没有一个人在藏东西。**
