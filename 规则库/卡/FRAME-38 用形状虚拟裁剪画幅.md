# FRAME-38 · 用黑色形状把画幅"改窄"（虚拟裁剪）⭐

## 规则
**画幅是固定的，观感画幅不是。** 在画面两侧（竖幅则是上下）放**坚实的黑色形状**，中间那块就读作另一种画幅。

## 我的判断
- **【B ⭐ 竖幅版就是"上下压黑"】** 书讲的是横幅两侧压黑得到竖感。镜像到 9:16：**在画面上下放暗块**（暗的天／暗的地面／前景暗物），中间那条就读作横幅。
  → 这是 [[FRAME-37 水平主题装进竖幅的四种做法]] 的**第五种做法**，且最直接。
- **【C · 与 [[FRAME-01 布光决定给多少信息]] 是同一手段的两种用法】** FRAME-01 用光控制**看得见多少**（信息量→情绪）；本卡用光控制**看得见多宽**（观感画幅）。**同一个暗块，两个作用，同时生效。**
- **【C ⭐ 透视篡改对我们不可用，但它的目的可用】** 我们不画分镜图，**没法手动改消失点**。但书说篡改的目的是「让轮廓线更接近垂直，效果**更像长焦镜头**」——**那我们直接用长焦就行**（[[FRAME-09 焦距决定景深与畸变]]）。
  → **画师靠篡改透视模拟的东西，我们靠指定焦距真的做出来。** 这是本流水线相对手绘的一处优势。
- **【C · 跨书印证】** FI-1 的农夫与木桶那例也用了同一手段（「使用强烈的投影效果……将画面进行非实质性的虚拟裁剪」）。**同一作者两本书各讲一次，是其常用手法。**

## 失败模式
> 屋顶透视角度**太过倾斜与明显**，以至于**无法直接用于构图**，还会**干扰观众注意力**
