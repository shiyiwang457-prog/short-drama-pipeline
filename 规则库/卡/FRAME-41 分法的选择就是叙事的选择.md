# FRAME-41 · 二分／三分／四分：选哪一种，就是选这镜讲什么

## 规则
分割方式不是构图偏好，**是叙事选择**。三种各有明确的性格与专用场合。

## 我的判断
- **【B · 三档速查】**
  | 分法 | 性格 | 用在 |
  |---|---|---|
  | **三分** | 平衡、自然 | 默认；大多数镜头 |
  | **二分** | **刻意、机械、冲击力大** | **闪回 · 转场 · 异常记忆**——书明说"略显奇怪"，别乱用 |
  | **四分** | 极端；**元素之间距离更大** | **史诗感 · 拉开张力线** |
- **【C ⭐ 阿兹特克那例说清了取舍的本质】** 四分法保留张力但取景更紧；三分法要**扩大取景**才装得下同样的元素，于是**镜头的主题从"战士"变成了"战士与环境的关系"**。
  → **分法的选择 = 这一镜到底在讲谁。** 这比"哪个更好看"重要得多。
- **【C · 二分法在《纪念日》里有明确用处】** 全片有 DV 影像与现实两轨交织。**"屏幕里她还在 → 切出来他一个人"**这个反复出现的落差，正是书说的"闪回/转场/非同寻常的记忆"——**二分法构图是它的对口手段**，而且全片只在这几处用，不会滥。
- **【C · 与 [[FRAME-32 橡皮筋：关键点距离决定张力]] 同源】** 四分法之所以有史诗感，是因为**它把关键点拉得更开**。分法只是达成"拉开"的一种度量方式。
