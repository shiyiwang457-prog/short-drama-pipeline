# FRAME-08 · 俯拍压抑 · 仰拍霸气（机位高度 → 权力关系）

## 规则
**机位相对角色视线的高低，直接翻译成角色的权力位置。** 但书强调：**光是配套的**，只改机位不改光，效果减半。

## 我的判断
- **【B ⭐ 俯拍那段的第二句才是关键】** "**我们几乎看不见他周围究竟存在着什么，就像身陷沼泽的他自己也不清楚一样**"——**俯拍的压抑不是来自角度，是来自角度带来的信息剥夺**。这与 [[FRAME-01 布光决定给多少信息]] 是同一个机制。
  → **写俯拍时必须同时写"看不见什么"**，否则只是一个高角度。
- **【C · 三件配套】** 书给的压抑构图是三样东西叠加：①机位低于/高于视线 ②**周围元素形成包围圈**（拳头／烟／墙上光影）③**主体在视觉中心且被压小**。只写机位，另外两样模型不会自己补。
- **【C · 与 [[BODY-30 自我感觉的胀大与缩小]] 配合】** BODY-30 是**人物自己**缩小（肩收、下巴回）；本卡是**镜头**让他缩小。两者叠加最强，但**也可以故意反着用**——仰拍一个体积缩小的人＝外强中干。

## 失败模式
只写"俯拍"而不写**俯拍要压出什么**（看不见周围／被包围／被压小）。
