# BODY-11 · 正确行走的部件级基线

## 规则
行走＝**躯干先发力前引** → 提髋 → 提膝 → 小腿前伸 → **脚跟先着地** → 支撑腿脚弓/脚掌/脚趾蹬地推送重心。摆臂与迈步**异侧同步**。

## 我的判断

- **【C】** 这是**步态基线**。人物的步态特征应写成相对此基线的偏离（脚跟不先着地→沉懈；脚距过大→左右晃摆）。
- **【C】** 摆臂的「虎口向上/向下」「不超过腹中线」「30 度」是**罕见的量化描述**，可直接写进提示词。

## 失败模式
> 上体后仰、下肢先于躯干动作 → 挺腹送髋松懈
> 步幅不均或重心停留长短不等 → **身体向一侧晃动，严重者给人以瘸的感觉**
> 内、外八字脚 → 扭摆、扣膝、晃身
> 一开始就全脚掌着地、后脚推送无力 → **沉懈感**
> 后脚向上蹬送而非向前 → **身体上下蹿动、跳跃**
