# FRAME-01 · 布光决定给多少信息，信息量决定情绪 ⭐⭐

## 规则
**同一个场景、同一个视点，只改光，就能改情绪。** 机制是：光控制观众**看得见多少**——
**看得越全 → 越踏实放松；看得越少 → 越不安恐惧。**

## 我的判断
- **【B ⭐ 这是一条干净的单变量规则】** 书明说恐惧感"**与我们的视点无关，只与布光有关**"。这在本库里罕见——大多数规则是多因的，这条是单因的，**因此也最容易在提示词里操作和验证**。
- **【C · 可提示化的操作轴】** 不要写"气氛压抑"（G0），要写**给多少**：
  | 情绪 | 光的写法 |
  |---|---|
  | 踏实 · 放松 · 日常 | 光源多、无死角、暗部有细节、能看清全部陈设 |
  | 不安 · 恐惧 | 只有一处光源、大面积不可见、**关键区域在暗部** |
  | 亦正亦邪 | 只照亮脸的一半 / 眼睛在暗部 |
- **【C ⭐ 雏菊例给了一条硬约束】** **不许写"光照不到的东西"。** 提示词里如果既写了"只有一盏台灯"又详细描述了房间四角的陈设，是自相矛盾的——模型会把两者都画出来，结果光效垮掉。
  → **写光之前先决定：这个光下，哪些东西根本不该出现在画面里。**
- **【C · 与本流水线的成本关系】** 布光是**零成本的情绪手段**：同一场景不换机位、不换动作，只改光，就换了一个世界。对按块计费的生成，这是性价比最高的一条。

## 失败模式
> **打开全部灯与窗户……对所有事物一览无余**，这样的光线环境**无法给我们留出更多的想象空间**
