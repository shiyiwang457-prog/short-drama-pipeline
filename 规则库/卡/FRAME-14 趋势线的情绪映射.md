# FRAME-14 · 趋势线的情绪映射（曲线／直线／对角线）

## 规则
每个镜头**先选一种趋势线**（水平／垂直／对角／曲线），它决定这个镜头的性格。

## 书上怎么说

> 📖 **原文引用已移除**（版权）。请查阅原书 [29, 50, 62, 65] 页。
> 本卡的「规则」与「失败模式」是对该处内容的提炼与再表述。


## 我的判断
- **【B · 映射表】**
  | 趋势线 | 情绪 |
  |---|---|
  | 曲线 | 柔软 · 友善 · 精致 · 平和 · 亲和 |
  | 直线／折线 | 强劲 · 干练 · **苛刻** · 确定性 |
  | 对角线 | **动感 · 冲击力** |
  | 扭曲缠绕的曲线 | 书特别注明「另当别论」——不适用上面那条 |
- **【C · 跨书印证】** [[BODY-18 直线与曲线的情绪映射]]（侯寄南）说的是**人体线条**，本卡说的是**画面线条**。两本书在同一映射上一致，置信度高。
- **【C ⭐ 趋势线由环境承载，不由人物承载】** 书列的载体全是环境物（树枝／云／涂鸦）。所以**趋势线属于站1 场景卡**，写法是：「画面中的主导线条是……」。
- **【C · 同一场景可换趋势线】** 移动机位就能把曲线换成折线——这是**零成本的情绪切换**，与 [[FRAME-01 布光决定给多少信息]] 同类。

## 失败模式
不选趋势线 → 构图方向由画面内容**随机决定** → 同一场戏里镜与镜的性格互相打架。
