# FRAME-25 · 主体形状的情绪映射（尖锐／圆滑／方／塌陷）

## 规则
**人物的整体外轮廓形状本身就在说话**，与画面的趋势线（[[FRAME-14 趋势线的情绪映射]]）是两回事：那是**环境的线**，这是**人的形**。

> 本卡的「规则」与「失败模式」是对该处内容的提炼与再表述。


## 我的判断
- **【B · 映射表】**
  | 形状 | 情绪 |
  |---|---|
  | 尖锐 · 支棱八叉 | 紧张 · 活力 |
  | 圆润 · 柔和 | 善意 · 舒缓 · 不具攻击性 |
  | **长方形** | **中规中矩、索然无味**（书原话） |
  | **立方体** | **自信** |
  | **向内收紧／塌陷** | **失落 · 不安全 · 被逆境压垮** |
  | 直线曲线对角线混杂 | 困惑 |
- **【C ⭐ 跨书印证 [[BODY-30 自我感觉的胀大与缩小]]】** 侯寄南从**演员自我感觉**讲"缩小"；本书从**画面轮廓**讲"向内收紧甚至塌陷"。两本书、两个角度、同一个可见结果。**置信度高，可优先实测。**
- **【C ⭐ "背景也要匹配"是本卡最容易漏的一半】** 书说轻松情境下**背景也应安静稳定**，且**发型、衣服、影子、背景建筑都为情绪作贡献**。→ 写人物形状时**必须同时定背景形状**，否则两者打架。
- **【C · 与 [[BODY-34 动物摹拟压缩人物形体]] 是同类压缩器】** 动物名压缩一整套形体；形状词（尖/圆/方/塌）压缩轮廓基调。**两者都停在形体卡，推导成部件描述后才进提示词。**

## 失败模式
> 长方形身型「看上去**中规中矩甚至有些索然无味**」——**没有形状选择 = 默认得到最无趣的那一个**。
