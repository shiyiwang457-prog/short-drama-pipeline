# FACE-13 · 微相的套路禁用清单 ⭐

## 规则
书点名了三个被用滥的面部/形体套路。**这三个恰好是生成模型的默认输出**，必须显式禁掉。

## 书上怎么说

> 本卡的「规则」与「失败模式」是对该处内容的提炼与再表述。


## 我的判断
- **【C ⭐ 这份清单对 AI 比对演员更要紧】** 生成模型的训练数据里全是这三个套路。**写"紧张"大概率得到抓衣角，写"哭"大概率得到手捂脸。** 因此它们必须进**负向提示词**，不能只靠正向描述覆盖。
- **【C · 三条替代写法】**（依据白兰度那段的结构）
  | 套路 | 替代 |
  |---|---|
  | 抓衣角 | 写**被压住的部件**：手放在原处不动，但指节用力 |
  | 眼角抽动 | 写**过程**：眉头蹙起 → 尽力平复 → 再蹙 → 终于平息 |
  | 手捂脸 | 写**不遮挡**：没有泪水，眼睛深得看不到底 |
- **【C · 与 [[BODY-38 典型是类的特征加个性]] 同源】** 套路就是"类的平均值"在面部的版本。**破套路 = 加个性偏离。**
- **【C · 待办】** 本卡应当在提示词 skill 里落成一张**负向词表**，与平台的 negative prompt 字段对接。

## 失败模式
> 使微相**过于直白和套路，失去了原有的意味**
