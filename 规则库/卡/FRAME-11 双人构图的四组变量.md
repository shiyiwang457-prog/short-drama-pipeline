# FRAME-11 · 双人构图的四组变量（无台词也能说清关系）⭐⭐

## 规则
两个人坐在同一张桌子前，**不说一句话**，光靠构图就能说清关系。书给了**四种可直接取用的配置**。

## 我的判断
- **【B ⭐ 这是站4 关系轴线目前唯一一张有具体做法的卡】** 之前站4 只有轴线方向的规则，本卡给了**关系怎么用画面写**。
- **【C ⭐ 四组变量是可组合的，共 4 个开关】**
  | 开关 | 值 |
  |---|---|
  | 中间有无障碍物 | 有／无 |
  | 两人背景是否相同 | 同／异 |
  | 受光是否均等 | 均／偏 |
  | 明暗对比强度 | 平／一方强 |
  → 写双人场景时**先拨这四个开关，再写台词**。
- **【C · 直接可用于《纪念日》场 2】** 场 2 是双人对话（他 · 她），台本里她在**说服他带上磁带**，最后被他驳住。按四组变量：
  - 前半（顺畅）：**无障碍物 ＋ 受光均等** → 配置 1
  - 「你有包」之后（她被驳住）：**她这一侧变暗 / 他明暗对比更强** → 配置 3＋4，视线自然被他吸引
  - 全程**背景相同**（同一间出租屋）——不要用配置 2，否则会读成"两人已经不属于同一个世界"，与本场情绪不符
  → **这一条可以直接改进场 2 的提示词，且不增加成本。**
- **【C】** 与 [[BODY-36 群体中的关系可由体态读出]]（侯寄南：体态）、[[FACE-04 眼神映射关系与地位]]（侯寄南：视线）构成三层：**构图 · 体态 · 视线**。三层同向才最强。

## 失败模式
两人同框但**关系全靠台词**，构图上两人是等价的——画面等于没参与叙事。
