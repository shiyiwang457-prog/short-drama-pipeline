# FACE-07 · 特写的颗粒度是睫毛级 ⭐⭐

## 规则
特写镜头下**可写的最小单位是睫毛、眼神的瞬间变化、面部肌肉的细微动作、皱纹**。
书给出了这一级的**部件名单**——这是面部 G2 的骨架。

## 我的判断
- **【B ⭐ 这份名单直接进部件清单】** 特写级可写部件：**睫毛（颤动）· 眼神（瞬间变化）· 面部肌肉（细微动作／线条）· 皱纹**。
  → 已并入 [[部件清单]] 系统六。
- **【C ⭐ 「皱纹指示性格」这条极有用】** 皱纹是**静态的、由长期状态刻出来的**，因此它属于人物基线而非当下情绪。**特写里写皱纹＝写这个人过去几十年的表情习惯。**（一个常年皱眉的人，即使此刻放松，眉间的纵纹仍在）
- **【C · 与 [[FACE-05 小景别下故意即作假]] 配套读】** FACE-07 说要写到睫毛级，FACE-05 说不许有"故意"。**两者合起来 = 极小的幅度 + 极高的精度**。这正是特写最难写的原因：不是写得少，是写得**细而不刻意**。
- **【C · 对本流水线的直接后果】** 此前 G2 的"部件级"停在手/肩/重心这一层。**特写镜头必须再下一层。** 一个特写的 G2 若只写到"眼神复杂"，等于什么都没写。

## 失败模式
> 影片要求面部表情**既细腻又可信**。（只细腻不可信＝做作；只可信不细腻＝空白）
