# FRAME-36 · 换画幅只有三种改法，改之前先问一个问题 ⭐⭐

## 规则
**三种改法**：只调高度 / 只调宽度 / 两者折中。
**改之前必须先答**：原画幅里**哪一部分**承载了最有价值的信息——顶部、底部，还是两边？

## 我的判断
- **【B ⭐ "上下滑动画面就换了威胁来源"是竖屏最强的一个免费手段】** 同一个场景、同一批元素，**取景窗上移 → 威胁来自上方的物体；下移 → 威胁来自下方的环境**。不改机位、不改人物、不加元素。
  → 《纪念日》场 16 是**海边**：取景偏下 = 危机来自海（自然）；取景偏上 = 天压着他。**目前是三段分层居中，等于两者都没选。**
- **【B ⭐ 竖幅擅长表现等级差别】** 这是书给竖幅的明确定位。→ 双人戏里若有**地位差**（场 2 的「你有包」把她驳住），竖幅是有利画幅，应当**用上下位置差把它写出来**。
- **【C · 「底部填满 vs 周围留空」是同一竖幅的两档】** 责任重大 ⟷ 超凡脱俗。**都是竖幅，差别只在底部给谁。**
- **【C · 裁剪的判据是"要去哪儿"】** 海盗例：右边远处的大船不能切，**因为它交代了目的地**。→ 裁剪前先问：**哪个元素承载"这是要干什么"？那个不能动。**

## 失败模式
> **平均裁掉，取中构图**（不判断哪边的信息更值钱）
