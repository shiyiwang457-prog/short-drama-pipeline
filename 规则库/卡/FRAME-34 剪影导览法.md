# FRAME-34 · 剪影导览法：先把所有人压成黑影看一遍 ⭐⭐

## 规则
写多人镜头前，**先把所有角色想象成纯黑剪影**，看它们的**形状组合**是否构成一条清晰的流动线。
**看不出流动线，就说明这个构图没有秩序。**

## 我的判断
- **【B ⭐ 这是一个可执行的自查动作】** 多人镜头的提示词写完后问：**如果把这些人全变成黑影，还看得出谁是主角、视线该往哪走吗？** 看不出就重排。
- **【C ⭐ 剪影必须靠光才成立】** 书特意点出"**在轮廓光的帮助下**提高了辨识度"。→ 逆光/轮廓光是剪影法的**必要条件**，不是风格选择。写多人剪影镜头必须同时指定光位。
- **【C · 四种形状可直接选】** 写多人站位时**先选一个形状**（倒弧／垂直排／之字／纵向流动），再安排人。这与 [[FRAME-25 主体形状的情绪映射]] 是同一层思路：**形状先于内容**。
- **【C · 可反用且书明说】** "**协调的流动感与戛然而止的断点都是我们需要的**"——**断点是手段不是失误**。用在需要突变的地方。
- **【C · 与 [[FRAME-24 跨镜识别锚]] 是同一件事的两端】** FI-1 说识别锚要"任何布光下可辨认"；本卡给出**检验方法**：压成剪影还认不认得出。

## 失败模式
> 令**观众的眼睛在画格内漫无目的地乱转而失去秩序感**
