# FRAME-06 · 背景是一个角色，不是一块布景 ⭐

## 规则
**机位不动、景别不动，只改光，背景就换了一个性格。** 场景卡里必须写背景"在说什么"，不能只写它"是什么"。

## 我的判断
- **【B ⭐ 这是站1 场景卡的核心依据】** 场景卡不能只写「海边 · 黄昏 · 晴」这类**客观条件**，必须多一栏：**这个背景此刻在说什么**（稳定／不确定／不祥／中性）。
- **【C · 夜景那段给了三个可写的机制】**
  | 机制 | 写法 |
  |---|---|
  | 轮廓消失 | "形状与轮廓不再清晰" |
  | **间隙合并** | "山与山之间的空隙连成一片"——这条最具体，也最容易被忽略 |
  | 动态被淹没 | "画面里几乎没有可辨的运动" |
- **【C · "只有一处光区引人注目"是留白的做法】** 全暗＋一处亮 = 观众自动盯住那一处并预期事件。见 [[FRAME-01 布光决定给多少信息]]。
- **【C · 对《纪念日》的直接后果】** 场 16 的场景卡目前只写了「海边／室外／黄昏／晴／中风→大风」，**没有写这片海在说什么**。按本条应补一栏——它三年没变，是**中性的、不参与**的，这本身就是台词（导演注记：「它每年都开，和她没有关系」）。

## 失败模式
把背景当作"故事发生的地方"来写，而不是当作**一个会说话的角色**。
