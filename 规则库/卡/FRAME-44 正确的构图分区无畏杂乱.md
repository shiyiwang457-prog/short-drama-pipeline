# FRAME-44 · 分区做对了，杂乱就不是问题 ⭐

## 规则
**杂乱本身不是毛病，分区不清才是。** 只要构图区域划分与明暗对比处理好，环境里的杂物**不但不干扰，还能刻画人物**。

## 我的判断
- **【C ⭐ 这条修正了我此前的一个倾向】** [[FRAME-04 取精气神而非复制全部特征]] 和 [[FRAME-03 暗示优于直陈]] 都在说"少写、别堆细节"，我据此把提示词的环境栏压得很简。**本卡说：环境细节多不是问题，前提是分区清楚。**
  → 正确的做法不是「少写环境」，而是**「写环境时同时写清它属于哪一层、亮还是暗」**。
- **【C ⭐ 环境杂物能刻画人物，这是白给的信息量】** 「桌子、书、文件、家具风格**有助于刻画这间屋子主人的个性**」。→ 场 2 的出租屋目前只写「简陋的房间，衣架上挂着一件深色西装」——**可以再给两件东西**（比如摊开的杂物、没收的行李），**免费交代两人的处境**，只要它们在暗部。
- **【B · 「明暗交替」是保证每层可辨的机制】** 亮 → 暗 → 亮 的背景序列，让每一层的轮廓都有对比可依。这是 [[FRAME-31 建立纵深感的三个线索]] 的第四条线索，**可直接写**：「前景的花枝是暗的，中景的他被侧逆光照亮，远处的海面又是暗的」。
- **【C · 区域宽窄递变是第五条纵深线索】** 越近的区域越宽。竖幅里对应：**越靠画面下方的区域越宽**。

## 失败模式
> **视觉中心被杂乱无章的元素所干扰**（＝分区没做，不是元素太多）
