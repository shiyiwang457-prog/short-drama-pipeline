# FACE-09 · 电影里没有「群众」，每个人都有独立反应 ⭐

## 规则
**戏剧的群众是一个整体；电影的每个人都是独立的反应个体，而且这些反应会被特写检验。**
所以多人场景里，**不许写"其他人看着他"**——每个人的反应必须分别写。

## 我的判断
- **【B ⭐ 这是「听者反应」的第二条依据，且来自另一本书】** [[FACE-04 眼神映射关系与地位]]（侯寄南）给了**听者该怎么看**；本条（苏彭成引奥勃莱恩）给了**为什么每个听者都必须单独写**。
  ⚠️ 按抽取纪律 3（卡忠于单一出处），两条**不合并**。综合是 skill 运行时做的事。
- **【C · 对提示词的硬约束】** 多人镜头的 G2 必须**逐人列**，哪怕某人是"静止的"——那也要写清是哪种静止（[[BODY-37 气质四型与三个反应轴]] 的显隐档不同，静止的样子不同）。
  → **"背景人物自然反应"这种写法等于放弃控制**，模型会给一群同质的点头者。
- **【C · 成本权衡】** 逐人写会让提示词变长。折中：**主要听者写到部件级，次要人物写一行体态方向**（朝向 + 是否在看 + 体积档），但**不许省略**。
- **【C】** 与 [[BODY-36 群体中的关系可由体态读出]]（侯寄南）指向同一件事的两面：BODY-36 说**关系决定体态**，本卡说**每个人的反应必须单写**。两条一起用才完整。

## 失败模式
> 在剧场里，**转身注意主要角色的那一群人仍然是一个群体**。（写成群体 = 退回舞台逻辑）
