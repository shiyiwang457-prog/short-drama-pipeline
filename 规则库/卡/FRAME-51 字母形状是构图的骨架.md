## 规则

**构图的骨架可以用一个字母的形状来定**，形状选定了，元素往形状上摆。每种形状有各自的功能：

| 形状 | 功能 |
|---|---|
| **V 形** | 使画面的中心成为**关注的中心**；两边可放较暗的框架元素 |
| **H 形** | 水平那一横**连接两个主体**，两侧的两竖**构成动作发生的区域** |
| **Z 形** | 下降的对角线，只在人物所在的垂直方向处中断 |
| **U 形** | 略带斜视，人物在明亮背景下处于黑暗中 |
| **G 形** | 多个物体**互不干扰**，靠体量大小形成对比 |
| **星形** | 从一个点发散出所有对角线，**高度动态** |
| **螺旋形** | 把眼睛从阴影中的下半部**驱动到主要动作发生的上部** |
| **椭圆形** | 多个头部与背景物围成一圈，带来**自然的流动感** |
| **三角形** | 由若干头部与横向物构成的基本蓝图，稳 |
| **箭头形** | 有明确指向：最宽的一面在一侧、尖端指向另一侧，把视线推过去 |

## 我的判断

- **本卡与 [[FRAME-13 先画张力线再填元素]] 是同一动作的两半**（C）：FRAME-13 规定"先定趋势线再填元素"的**顺序**，本卡给的是**趋势线可以长成哪些形状**。用的时候是一件事：先选字母，再摆元素。
- **可直接写进生成提示词**（C）：「V形构图」「三角形构图」这类词属于摄影通用词汇，模型认得；比「构图要平衡」这种空词具体得多。
- 书上是**插图注释**形态（每条是"某页某图是什么构图"），不是条列的规则表——上表是我从 9 条注释里归纳的（B）。**归纳没有改变任何一条的原话含义**，每种形状的功能句都能在上面的原文里逐条对上。
- 未收录**中心构图**（p.219 图7-28「中心构图，将大量的明暗放在图片中，便于读取图像」）：它讲的是明暗分布不是骨架形状，归 [[FRAME-44 正确的构图分区无畏杂乱]]。

## 失败模式

元素各摆各的，画面读不出一个整体形状——观众的眼睛没有落点。

书上每一条注释都在指认"这张图的骨架是什么形状"，**反过来说：说不出骨架形状的构图，就是还没构图**。
