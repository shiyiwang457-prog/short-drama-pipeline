# FRAME-45 · 长焦把多个主体压成一体，等于宣告他们同等重要 ⭐⭐

## 规则

**长焦不只是"虚化背景"的工具，它是一个关系声明。**
被它压进同一个平面的两个元素，**在这一刻没有主次之分**。

想要主次 → **广角拉开**；想要"他们是一体的" → **长焦压合**。

## 我的判断

- **【B】本条与 [[FRAME-09 焦距决定景深与畸变]] 是同一件事的两层**：FRAME-09 讲**光学后果**（景深压缩、人贴背景），本条讲**叙事后果**（主次消失）。取卡时两张要一起读。
- **【C · 反用的判据】** 一场戏若明确有强弱关系（谁在压谁、谁在等谁），**不要用长焦把两人压在一起**——那会把你辛苦建立的强弱抹平。
- **【C · 符号化的条件】** p.189 那条要成立，需要**同一个物件在后续镜头里再次出现**。只压扁一次不会变成符号，**压扁 ＋ 复现**才会。

## 失败模式

**用长焦只为了"背景干净"，没意识到它同时宣告了"这些人平起平坐"。**
——一场有权力关系的戏被拍成了合影。
