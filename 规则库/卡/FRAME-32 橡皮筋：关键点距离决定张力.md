# FRAME-32 · 橡皮筋：关键点拉得越开，张力越大 ⭐⭐

## 规则
把画面里的叙事焦点当作**橡皮筋上的关键点**。
**拉得越远、越靠边 → 张力越大；挤在一起、都在中间 → 张力松弛。**

## 书上怎么说

## 我的判断
- **【B ⭐ 这是一条量化规则，可直接调】** 写多人镜头时，**先定关键点之间的距离档位**：
  | 想要 | 做法 |
  |---|---|
  | 张力大 | 关键点**拉到画面两端**，或**贴近边缘** |
  | 稳定 | 关键点构成**等边三角形**或都在中央 |
  | 压抑（≠张力） | 关键点**靠得很近**且一方在上方压着 |
- **【C ⭐ 「近＝压抑，远＝张力」是两个不同的轴】** 飞艇那两例说清了：**低飞靠近＝沉重压抑，但拉伸张力反而减少**。所以不能笼统说"张力"——**要先分清要的是"张力"还是"压迫"**。
- **【C ⭐ 图例 1.48 是竖屏的免费手段】** **抬高地平线** → 顶部空间被挤压、底部释放 → 张力增强。**这一招不改人物、不改机位，只改地平线高度**，成本是提示词里一句话。
  → 场 16 镜 1 目前写「海平线压在画面上三分之一处」——**这是"低地平线"，给的是开阔与释放**。若某一镜要张力，可反过来把海平线抬到上二分之一。
- **【C · 例外那条防止误用】** 两人贴脸对骂**没有拉伸关系但张力极大**——说明**距离只是张力的一个来源，不是唯一来源**。近距离的张力靠表情、杀气、褶皱、角度。

## 失败模式
关键点**挤在一起且都在画面中央** → 橡皮筋松弛 → 画面没有张力。
