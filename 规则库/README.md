## frontmatter 字段

| 字段 | 用途 |
|---|---|
| `id` `型` `证据档` | 卡的身份。型＝必须/禁止/映射/量化；档＝A直引/B转述/C推论/D无依据 |
| `出处书` `出处章` `出处页` `出处文件` | 引证四件套，缺一不可 |
| `站点` | **路由用**——skill 跑到哪一站取哪些卡 |
| `影响` | 影响 G1 还是 G2 的哪一项 |
| `适用景别` `适用场景类型` `适用媒介` `表演风格档` | 筛选条件 |
| `本流水线适用` | false ＝ 书上有但我们用不上（如舞台专用），登记备查 |
| `实测` `实测日期` | **由回测回写**。书给规则，实测告诉你在这个模型上有没有效 |
| `冲突` `相关` | 双链。冲突卡必须互相标注 |

## 建 Base 视图（建议）

字段就绪，可直接建查询视图，例如：
- 「站 6 要用的所有卡」→ `站点 contains 站6`
- 「实测无效的卡」→ `实测 == 无效`
- 「A 档直引占比」→ 按 `证据档` 分组
