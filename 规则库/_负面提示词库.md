# 负面提示词库（平台负向框专用）

> 2026-08-20 立 ｜ 来源：PM 提供的实战清单
> 🔴 **只放平台的负向词输入框，绝不写进画面描述段**——那里负向词无效甚至反读。

---

## 为什么这份清单和「负向词门禁」不冲突

两个位置，两套规则：

| 位置 | 负向词 | 理由 |
|---|---|---|
| **画面描述段**（提示词正文） | 🔴 **禁止**，门禁查为 0 | Seedance 官方：模型忽略；更坏的是「不要抓衣角」被读成「抓衣角」 |
| **平台的负向框**（独立字段） | ✅ **就该写这些** | 那个字段本来就是给负向条件用的，模型按不同通道处理 |

⚠️ 若平台**没有**负向框，本清单里的项要么转成正向表述写进正文，要么放弃。

---

## A 组 · 人物一致性（几乎所有项目都要）

```
禁止男女主换脸；禁止五官、脸型、年龄变化；禁止发型、发色变化；
禁止服装和配饰变化；禁止人物身材和身高变化；
禁止男女人物左右位置随机交换；禁止牵手左右手切换；
禁止人物动作瞬移；禁止身体姿态突然跳变。
```

## B 组 · 肢体畸变（几乎所有项目都要）

```
禁止手部畸形；禁止手掌变形；禁止手指数量错误；禁止多余手指；禁止手指粘连；
禁止两个人手掌融合；禁止牵手出现三只手或四只手；
禁止接吻时脸部融合；禁止鼻子融合；禁止嘴唇融合；禁止嘴唇畸形；
禁止头部穿模；禁止接吻突然变成拥抱；禁止拥抱时出现多余手臂。
```

## C 组 · 表演分寸（按风格档取用）

```
禁止人物直视摄影机；禁止夸张害羞；禁止夸张甜笑；禁止大笑；禁止哭泣；
禁止偶像剧式过度表演；禁止商业爱情MV摆拍。
```

⚠️ **「禁止人物直视摄影机」有适用条件**——见下方冲突表。
本组与 [[FACE-05 小景别下故意即作假]]、[[BODY-16 渲染不得过分]] 同源，是书证规则的平台侧落法。

## D 组 · 画质与镜头（按项目取用）

```
禁止过曝；禁止无意义闪白；禁止突然快速变焦；禁止高速推镜；禁止360度旋转镜头；
禁止鱼眼镜头；禁止极端广角畸变；禁止数字高斯模糊；
禁止塑料皮肤；禁止CG感；禁止动漫感；禁止AI假人感。
```

⚠️ **「禁止鱼眼／极端广角畸变」有适用条件**——见下方冲突表。

## E 组 · 场景专用（只在有该元素时才加）

```
【烟花】禁止烟花出现在人物脸前；禁止烟花遮挡人物五官；禁止烟花位置跳变；禁止烟花把夜晚照成白天。
【舞台/人群】禁止舞台结构变化；禁止背景观众复制粘贴；禁止所有观众完全同步运动；禁止背景人物突然消失或瞬移。
```

🔴 **E 组必须按镜取用**：没有烟花的镜写「禁止烟花…」＝ 给模型一个它本来不会画的东西，**反而可能提示它画烟花**（同「不要抓衣角」的机制）。

---

## 🔴 冲突表：这两条与常见画面直接打架，用前必查

| 清单项 | 什么时候必须豁免 | 实证 |
|---|---|---|
| **禁止人物直视摄影机** | 🔴 **POV／自拍／DV 视角全部豁免**——第一人称下角色对着镜头说话是叙事本身 | 森林 POV 场 1：男孩转身看向镜头问「你还行吗」，直视是必须的 |
| **禁止鱼眼镜头／极端广角畸变** | 🔴 **手臂长度自拍镜豁免**——近距离广角的透视夸张是自拍的真实特征 | 山顶自拍场 3：参考图本身就有明显广角透视 |

**处理办法**：这两条从该镜的负向框里**删掉**，同时在正文里正向写清楚要什么——
例：「广角近距离拍摄带来的**轻微透视夸张**」（写"轻微"来约束程度，而不是靠负向禁止）。

## 使用流程

```
① 取 A 组 ＋ B 组（基本盘）
② 按风格档取 C 组、按项目取 D 组
③ 镜里有烟花/舞台/人群才加 E 组对应块
④ 过冲突表：POV/自拍/DV 镜删「禁止直视摄影机」；自拍镜删「禁止鱼眼/广角畸变」
⑤ 粘进平台负向框，正文里一个字都不放
```
