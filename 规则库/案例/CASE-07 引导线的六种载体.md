# CASE-07 · 引导线的六种载体（牛仔 · 老电话 · 偷窥）

> 趋势线是抽象的，但它必须由**画面里真实存在的东西**承载。书给了三组示范，共六类载体。

## ① 牛仔困境（p.38）—— 地形与人体都能当线
> 图 B：**岩石纹理与地势走向**都指向那个身处绝境的牛仔，瞬间我们感受到构图后面隐藏的戏剧张力。
> 图 C：背景中的很多线条，比如**栅栏、左边的山脉、右边墙壁投下的影子**，都把我们的视线引向牛仔。另外，还有很多由**连续的隐藏点**制造出的**无形引导线**，例如**枪柄、坏人的指关节**，都指向了岌岌可危的牛仔头部。

**六类载体**：
| 类 | 例 |
|---|---|
| 地质纹理 | 岩石纹理、地势走向 |
| 人造结构 | 栅栏 |
| 远景轮廓 | 山脉 |
| **投影** | 墙壁投下的影子 |
| **道具指向** | 枪柄 |
| **人体局部** | 坏人的指关节 |

→ 后两类是**由离散的点连成的无形线**，不是画出来的线。这是最容易被漏掉的一类。

## ② 老式电话（p.54 情感传达的"藏与露"）—— 光本身就是线
> 低机位仰拍，为女孩打上一束**以对角线形式斜穿画面的轮廓光**；再为背景打上适当的光以便看清故事发生的地点（**光的强度不能太大，否则神秘感就会消失**）。
> **轮廓光与背景石柱头的亮部都指向这个镜头动作的发生处——老式电话拨盘——而带有一定亮度的电话线所形成的圈又把这个视觉中心围起来加以强调。**

→ **光可以是线**（对角线轮廓光），**亮部序列可以是线**（轮廓光 → 石柱头 → 电话），**实物可以围成圈**（电话线）。

## ③ 偷窥视角（p.56 视点的选择）—— 用唯一的直线在曲线丛中标出重点
> 这个偷窥的视角是从**花园灌木丛后侧**拍摄的……镜头与角色之间**隔着多层植物**，创造了一种**隐秘的空间感——既想搞清楚他们的谈话内容又不想被发现**。
> 为了使观众在如此繁杂的画面中快速捕捉到叙事重点，**角色背后的白墙无疑是整个画面的亮点**。而**他们身后的那扇门是这个画面中唯一的直线，这也与各种呈曲线状态的植物形成了鲜明对比，从而突出了叙事重点**。

→ **在一堆曲线里放一条直线**，那条直线就是重点。这是 [[FRAME-14 趋势线的情绪映射]] 的反向用法：不是用趋势线定基调，而是**用一条异类线定焦点**。

## 怎么用
写提示词时，**引导线不能写成"画面有引导线"**（模型不懂），要写成载体：
- ❌「构图有引导观众视线的线条」
- ✅「沙地上的风痕与远处海堤的走向都朝向他」
- ✅「一束斜穿画面的光落在他手中的机器上」
